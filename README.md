---

## 📌 Overview

This repository is a **comprehensive Game Design Document (GDD) archive** containing:

- **15 Existing Games** — Prototypes and platforms built with HTML5 Canvas, TypeScript, Godot 4, Rust/Web3
- **10 New Concepts** — Original GDDs covering Tower Defense, Roguelike, Match-3, Deck Building, City Builder, and more

Inspired by the curation philosophy of awesome-design, this pool applies design principles — color theory, typography, UX flow — to game design documentation.

## 🎯 How to Use

**Browse by mechanic** — Use the sections above to find games by genre.

**Read a GDD** — Each game folder contains a `README.md` with concept, mechanics, and tech stack. Design docs (`DESIGN.md`) and code docs (`CODE.md`) are included where available.

**Reference the gap analysis** — The coverage table shows which mechanics are covered and which are newly designed.

**Use the SKILL** — [`SKILL.md`](./SKILL.md) defines a Game Design Expert AI persona drawing from Miyamoto, Will Wright, Jonathan Blow, Jenova Chen, and Hideo Kojima.
