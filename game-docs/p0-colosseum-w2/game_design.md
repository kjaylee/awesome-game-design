## p0-colosseum-w2 (EastSea Protocol) 게임 설계 문서

### 프로젝트 컨셉
p0-colosseum-w2는 블록체인 기반의 탈중앙화 게임 콜로세움입니다. 플레이어들이 게임으로 경쟁하고, 그 결과가 온체인으로 기록되며, NFT와 토큰으로 보상받는 Web3 게임 생태계를 구현합니다.

### 메카닉 분류
**Strategy / Blockchain Colosseum (Web3)**

### 프로젝트 비전
게임 결과의 완전한 투명성과 플레이어의 자산 소유권을 보장하는 탈중앙화 게임 경쟁 플랫폼을 구축하여, 게이머가 실제 자산 가치를 가진 게임을 즐길 수 있는 환경 제공

### 게임플레이 콘셉트

#### 1. 콜로세움 1v1 대전
- **게임 선택**: 여러 게임 중 하나 선택 (체스, 카드 게임, 퍼즐 등)
- **상대 찾기**: 비슷한 실력의 플레이어와 매칭
- **베팅**: EST 토큰으로 베팅 (선택)
- **게임 진행**: 블록체인에 기록되지 않는 오프체인 게임
- **결과 기록**: 게임 종료 후 양쪽 서명으로 결과 기록
- **보상 수령**: 승자가 토큰과 경험치 획득

#### 2. 토너먼트 시스템
- **등록**: 입장료 납부 후 토너먼트 참가
- **브래킷**: 싱글 엘리미네이션 또는 라운드 로빈
- **매칭**: 이전 라운드 승자끼리 자동 매칭
- **우승 보상**: 상금 풀에서 우승자에게 배분
- **NFT 획득**: 우승자 또는 일정 순위 이상에게 NFT 발급

#### 3. 리더보드 및 평점
- **글로벌 랭킹**: 누적 승수 및 평점 기반 랭킹
- **게임별 랭킹**: 게임 유형별 분리 랭킹
- **시즌 시스템**: 월간/계절 리더보드 (보상 있음)
- **배지 시스템**: 특정 조건 달성 시 배지 획득

#### 4. NFT 자산 시스템
- **캐릭터 NFT**: 플레이어의 게임 아바타
- **승리 증명서**: 주요 우승 기록을 NFT로 발급
- **희귀 아이템**: 게임 내 강력한 아이템을 NFT화
- **마켓플레이스**: 플레이어간 NFT 자유 거래

#### 5. 토큰 경제 (EastSea Token)
- **게임 보상**: 매경기 승리 시 EST 획득
- **토너먼트 상금**: 우승 시 대량 EST 획득
- **스테이킹 보상**: 토큰을 스테이킹하면 일일 보상
- **거버넌스**: EST 홀더가 프로토콜 업그레이드 투표

### 핵심 재미 요소

#### 1. 경쟁의 진정한 가치
- 게임 승리가 실제 금전적 가치로 변환
- 투명한 블록체인 기록
- 사기 불가능한 시스템

#### 2. 자산의 소유와 거래
- 플레이어가 획득한 NFT를 완전히 소유
- 마켓플레이스에서 자유 거래
- 실제 수익 창출 가능

#### 3. 커뮤니티 거버넌스
- 토큰 홀더가 게임 규칙 결정
- 민주적 분쟁 해결
- 플레이어의 의견이 반영되는 게임

#### 4. 다양한 게임 선택
- 여러 장르의 게임 지원
- 각 게임마다 다른 전략 필요
- 특정 게임에 특화된 플레이어 보상

### 게임 포트폴리오

#### 지원 게임

**전략 게임**
- 체스/체크메이트
- 턴제 카드 게임
- 16진법(Hex) 기반 전략

**퍼즐 게임**
- 블록 배치 퍼즐
- 경로 찾기 퍼즐
- 논리 문제 게임

**리듬/반사 게임**
- 실시간 반응 게임
- 타이밍 게임
- 손목 게임 (손가락 민첩성)

### 게임플레이 루프

```
로그인 (지갑 연결)
  ↓
프로필 생성 (처음만)
  ├─ 캐릭터 선택
  ├─ 닉네임 설정
  └─ 초기 토큰 획득 (에어드롭)
  ↓
메인 메뉴
├─ 대전 찾기
├─ 토너먼트 등록
├─ 리더보드 보기
├─ 자산 관리 (NFT, 토큰)
└─ 프로필 관리
  ↓
대전/토너먼트 시작
  ├─ 상대 매칭 (30초)
  ├─ 게임 시작
  ├─ 게임 진행
  └─ 결과 기록 (블록체인)
  ↓
보상 수령
  ├─ 토큰 클레임
  ├─ NFT 확인
  └─ 경험치 상승
  ↓
[다음 게임]
```

### 경제 모델

#### 토큰 분배 (초기)
```
총 공급량: 1,000,000,000 EST

배분:
- 게임 보상 풀: 400M (40%) - 플레이어 보상
- 커뮤니티: 300M (30%) - 에어드롭, 인센티브
- 팀/운영: 150M (15%) - 2년 베스팅
- 파트너십: 100M (10%) - 생태계 파트너
- 유동성 풀: 50M (5%) - DEX 유동성

초기 토큰 가격: $0.01
초기 시가총액: $10M
```

#### 게임별 보상
```
매경기 보상 (1v1):
- 승자: 10-100 EST (상대 평점 기준)
- 패자: 0-10 EST (참여 보상)
- 도전 배수: 높은 평점 상대 승리 시 2배 보상

토너먼트 보상:
- 입장료: 100 EST
- 우승상금: 입장료 × 플레이어 수 × 40% (예: 100명 × 100 EST × 40% = 4,000 EST)
- 준우승: 총상금 × 30%
- 4강: 총상금 × 20%
- 8강: 총상금 × 10%
```

### 수익화 전략

#### 플랫폼 수익
- **거래 수수료**: 모든 거래의 2.5% (예: 토너먼트 상금, NFT 거래)
- **마켓플레이스 수수료**: NFT 거래의 5%
- **프리미엄 기능**: 월 $4.99 (광고 제거, 통계 상세 분석)

#### 커뮤니티 보상
- **총 게임 보상 풀**: 월 400M EST 중 10% = 40M EST
- **평균 플레이어 월 수입**: 10-100 EST (활동 수준에 따라)
- **상위 1% 플레이어**: 월 10,000+ EST 가능
