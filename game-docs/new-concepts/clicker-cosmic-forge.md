# Cosmic Forge — 우주를 빚는 손
## 게임 디자인 문서 v1.0

---

## 1. 게임 개요

### 1.1 제목 및 장르
- **제목**: Cosmic Forge — 우주를 빚는 손
- **장르**: Clicker / Incremental / Idle / Cosmic Simulator
- **플랫폼**: 웹 기반 (HTML5 + BigInt)
- **플레이 모드**: 싱글플레이 (오프라인 지원)
- **세션 길이**: 무한 (점진적 진행)
- **스케일**: 원자 (10^-10) → 우주 (10^80)

### 1.2 게임 컨셉
Cookie Clicker와 Universal Paperclips의 정신을 계승한 초월적 스케일의 인크리멘탈 게임이다. 원자 1개를 클릭에서 시작해 분자, 생명, 행성, 항성, 은하, 우주까지 창조한다. "상전이(Phase Transition)" 메카닉을 통해 게임 규칙 자체가 진화하며, "대붕괴 & 재탄생" 시스템으로 영구 진행을 제공한다.

## 2. 핵심 혁신 메카닉

특정 임계점 도달 시 게임의 규칙과 목표가 완전히 변화한다. 6개 상전이를 통해 게임이 진화하며, 각 단계마다 새로운 조합 논리를 배운다.

#### 6단계 상전이 상세

## 3. 6단계 상전이 설계

### Phase 1: 원자의 시대 (Atomic Age)
**목표**: 쿼크 → 양성자/중성자 → 원자 → 1 * 10^24 개 원자 도달

#### 기본 메카닉
- **클릭 효과**: 1 쿼크 생성
- **클릭 강화**: 마우스 연사 속도 업그레이드

#### 생산자 (오토클리커)
| 생산자 | 기본 생산량 | 초기 비용 | 설명 |
|--------|-----------|---------|------|
| 쿼크 제너레이터 | 1/초 | 10 쿼크 | 기본 생산 |
| 양성자 결합기 | 5/초 | 100 쿼크 | 쿼크 → 양성자 |
| 중성자 합성기 | 5/초 | 100 쿼크 | 쿼크 → 중성자 |
| 원자 조립기 | 1/초 | 1,000 쿼크 | 양성자+중성자 → 원자 |
| 슈퍼클러스터 생성기 | 100/초 | 1,000,000 쿼크 | 원자 대량 생산 |

#### 임계점
- **10^6 원자**: Phase 2 해금 (분자 합성)
- 도달 시간: 약 5분

#### 주요 업그레이드 (15개)
- 쿼크 생성 +10% (비용: 50 쿼크)
- 쿼크 생성 +25% (비용: 200 쿼크)
- 쿼크 생성 ×2 (비용: 1,000 쿼크)
- 양성자 생산 +50% (비용: 500 쿼크)
- 중성자 생산 +50% (비용: 500 쿼크)
- 원자 생성 가속화 (비용: 5,000 쿼크)
- 자동 수집 (비용: 10,000 쿼크)
- 클릭 강화 ×3 (비용: 50,000 쿼크)
- 등등 15개 총

### Phase 2: 분자의 시대 (Molecular Age)
**목표**: 분자 합성 → 화합물 → DNA → 1 * 10^36 분자 도달

#### 규칙 변화
- 이전: "원자 생산" → 현재: "분자 조합"
- 클릭 효과: 1 분자 합성 (원자 필요)
- 새로운 컨셉: 화학 결합 (H2O, CO2, DNA)

#### 분자 체계
```
원자 + 원자 → 분자
H + H → H2 (수소 분자)
O + O → O2 (산소 분자)
H2 + O2 → H2O (물, 초기 생명 단위)
C + H4 + O2 → CH4O (메탄올, 유기물 기초)
```

#### 생산자 (새로운 추상화)
| 생산자 | 생산량 | 초기 비용 | 설명 |
|--------|--------|---------|------|
| 분자 결합기 | 1/초 | 10,000 원자 | 원자 → 분자 |
| H2O 생성기 | 2/초 | 50,000 원자 | 물 분자 생성 |
| 유기물 합성기 | 0.5/초 | 100,000 원자 | 유기 화합물 |
| DNA 가닥 생성 | 0.1/초 | 1,000,000 원자 | DNA 분자 |
| 단백질 팩토리 | 0.05/초 | 5,000,000 원자 | 단백질 생성 |

#### 임계점
- **10^12 분자**: Phase 3 해금 (생명 배양)
- 도달 시간: 약 20분

### Phase 3: 생명의 시대 (Biotic Age)
**목표**: 세포 → 미생물 → 생물 → 1 * 10^48 생명 도달

#### 규칙 변화
- 이전: "분자 생성" → 현재: "생명 진화"
- 클릭 효과: 1 세포 분열
- 새로운 컨셉: 생태계 (먹이사슬, 진화)

#### 생명 진화 트리
```
세포 (가장 기초)
├── 박테리아 (미생물)
├── 원생동물 (원생생물)
└── 곰팡이 (진핵생물 초기)
    ├── 식물 (식물계)
    │   ├── 이끼
    │   ├── 고사리
    │   └── 꽃식물
    └── 동물 (동물계)
        ├── 무척추동물
        ├── 척추동물
        └── 포유류
            └── 인간 (?)
```

#### 생산자
| 생산자 | 생산량 | 초기 비용 | 설명 |
|--------|--------|---------|------|
| 세포 분열기 | 1/초 | 1,000,000 분자 | 세포 생성 |
| 박테리아 배양 | 2/초 | 5,000,000 분자 | 미생물 |
| 식물 농장 | 3/초 | 10,000,000 분자 | 광합성 생산 |
| 동물 사육장 | 1/초 | 50,000,000 분자 | 포식 생산 |
| 인간 사회 | 0.1/초 | 1,000,000,000 분자 | 문명 생산 |

#### 임계점
- **10^24 생명**: Phase 4 해금 (문명 관리)
- 도달 시간: 약 40분

### Phase 4: 문명의 시대 (Civilization Age)
**목표**: 부족 → 국가 → 우주 문명 → 1 * 10^60 문명 도달

#### 규칙 변화
- 이전: "생물 진화" → 현재: "문명 발전"
- 클릭 효과: 1 인류 탄생
- 새로운 컨셉: 기술 트리 (선사 → 고대 → 중세 → 근현대 → 미래)

#### 기술 발전
```
선사 시대 (불 발견)
→ 고대 (도시 건설)
→ 중세 (농업 발전)
→ 르네상스 (과학 혁명)
→ 산업 혁명 (기계화)
→ 정보화 시대 (디지털)
→ 우주 시대 (우주 탐사)
```

#### 생산자
| 생산자 | 생산량 | 초기 비용 | 설명 |
|--------|--------|---------|------|
| 부족 마을 | 1/초 | 100,000,000 생명 | 기초 사회 |
| 농업 제국 | 2/초 | 1,000,000,000 생명 | 식량 생산 |
| 산업 국가 | 5/초 | 10,000,000,000 생명 | 제조업 |
| 디지털 사회 | 10/초 | 100,000,000,000 생명 | 정보 혁명 |
| 우주 문명 | 20/초 | 1,000,000,000,000 생명 | 우주 정복 |

#### 임계점
- **10^36 문명**: Phase 5 해금 (항성 조율)
- 도달 시간: 약 80분

### Phase 5: 항성의 시대 (Stellar Age)
**목표**: 성운 → 항성 형성 → 은하 관리 → 1 * 10^72 항성 도달

#### 규칙 변화
- 이전: "문명 발전" → 현재: "항성 조율"
- 클릭 효과: 1 항성 점화
- 새로운 컨셉: 우주 시공간 조종 (중력, 에너지)

#### 항성 타입
```
적색 왜성 (적게 생산)
→ 황색 항성 (정상 생산)
→ 백색 항성 (고생산)
→ 초거성 (매우 고생산, 불안정)
→ 초신성 (단기 폭발, 극고생산)
→ 블랙홀 (영구 생산)
```

#### 생산자
| 생산자 | 생산량 | 초기 비용 | 설명 |
|--------|--------|---------|------|
| 성운 응축기 | 1/초 | 1,000,000,000,000 문명 | 항성 형성 |
| 항성 용광로 | 5/초 | 10,000,000,000,000 문명 | 에너지 생산 |
| 은하 제조 | 20/초 | 100,000,000,000,000 문명 | 은하 생성 |
| 블랙홀 발전소 | 100/초 | 1,000,000,000,000,000 문명 | 극한 에너지 |
| 우주 엔진 | 500/초 | 10,000,000,000,000,000 문명 | 우주 이동 |

#### 임계점
- **10^48 항성**: Phase 6 해금 (우주 창조)
- 도달 시간: 약 160분

### Phase 6: 우주의 시대 (Cosmic Age)
**목표**: 빅뱅 재현 → 우주 확장 → 1 * 10^80 (계산상 우주의 원자) 도달

#### 규칙 변화
- 이전: "항성 조율" → 현재: "우주 창조"
- 클릭 효과: 1 우주 폭발 (빅뱅 재현)
- 새로운 컨셉: 다중우주 & 대붕괴 시스템 (게임 최종 단계)

#### 우주 생성 메커니즘
```
엔트로피 축적 → 임계점 도달 → 대붕괴 → 빅뱅 → 새 우주 탄생
```

#### 생산자 (최종)
| 생산자 | 생산량 | 초기 비용 | 설명 |
|--------|--------|---------|------|
| 우주 발전소 | 1,000/초 | 10^18 항성 | 우주 에너지 |
| 다중우주 생성 | 10,000/초 | 10^24 항성 | 평행우주 |
| 시간 조종기 | 100,000/초 | 10^30 항성 | 시간 상대성 |
| 대붕괴 엔진 | 1,000,000/초 | 10^36 항성 | 최종 폭발 |

#### 도달 시간: 약 400분 (7시간)

## 4. 대붕괴 & 재탄생 시스템

### 4.1 대붕괴 (Big Crunch)
#### 개념
우주가 10^80에 도달하면 자동으로 대붕괴가 발생하고, 모든 것이 초기화되지만 강력한 영구 보너스를 획득한다.

#### 대붕괴 보상
- **영구 보너스**: 다음 우주부터 기본 생산량 ×2
- **기억 시스템**: 이전 우주의 "에코" 기록
- **업적 시스템**: 달성한 마일스톤 영구 유지

#### 재탄생 (Rebirth)
- **새 우주 규칙**: 매 대붕괴마다 1가지 규칙 변경
  - 예: "항성이 2배 빠르게 생성"
  - 예: "분자 합성 비용 50% 감소"
  - 예: "클릭 효율 3배"

### 4.2 영구 업그레이드 시스템 (50개)

#### 1~10번: Phase 1 영구 업그레이드
- 쿼크 생성 기본값 +10% (매 대붕괴)
- 원자 생산 +5%
- 쿼크 생성 속도 +3% (클릭)
- 등등

#### 11~20번: Phase 2 영구 업그레이드
- 분자 합성 +10%
- 유기물 생산 +8%
- DNA 생산 가속화
- 등등

#### 21~30번: Phase 3 영구 업그레이드
- 생명 진화 속도 +15%
- 식물 성장 +10%
- 동물 번식 +12%
- 등등

#### 31~40번: Phase 4 영구 업그레이드
- 문명 발전 +10%
- 기술 연구 속도 +20%
- 우주 문명 해금 시간 -30%
- 등등

#### 41~50번: Phase 5~6 영구 업그레이드
- 항성 형성 +50% (누적)
- 블랙홀 발전소 생산 +25%
- 대붕괴 카운터 -10% (더 빨리 도달)
- 등등

## 6. 숨겨진 마일스톤 & 업적 시스템 (100개)

- **수집 마일스톤** (10개): 원자 10, 100, 1K, 10K, ... 10^60 도달

- **시간 마일스톤** (10개): 플레이 시간 10분, 1시간, 10시간, ...

  - "클릭만 사용해서 Phase 3 도달"
  - "오프라인 진행으로 10배 진행"

- **업적 레벨**: 0~100 레벨 (경험치 기반)
- **업적 특전**: 특정 업적 달성 시 보너스

  - 50개 업적: 대붕괴 시 ×3 보너스 (기본 ×2에서 ×6)
