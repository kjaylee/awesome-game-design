# 먹빛 서울 (Ink Seoul) — 붓 한 획이 세상을 바꾼다

> **장르**: 파쿠르 액션 / 리듬 퍼즐  
> **플랫폼**: PC (Steam), PlayStation 5, Nintendo Switch  
> **개발 규모**: 인디 AA (팀 8~12인, 개발 기간 24개월)  
> **타겟 등급**: 12세 이상  
> **레퍼런스**: Okami (먹 비주얼) + Mirror's Edge (파쿠르 이동) + Hades (서사 루프)

---

## 1. 게임 개요

### 1.1 핵심 컨셉

**먹빛 서울**은 2077년 사이버펑크 서울을 배경으로, 플레이어가 '먹(墨)의 정령'을 조종해 도시를 가로지르는 **한국 전통 수묵화 스타일 파쿠르 액션** 게임입니다.

> "이 도시의 색은 누군가 빼앗았다. 붓을 들어라. 서울에 먹빛을 돌려줘라."

모든 레벨은 처음엔 **회색빛 스케치** 상태로 시작하며, 플레이어가 이동하고 행동할수록 **먹이 번지듯 세계에 색과 생명이 복원**됩니다. 게임의 핵심은 움직임 자체가 예술 행위이며, 완주한 경로가 그대로 한 폭의 수묵화 작품이 되는 것입니다.

### 1.2 장르 & 플랫폼

| 항목 | 내용 |
|------|------|
| 메인 장르 | 3D 파쿠르 액션 |
| 보조 장르 | 리듬 퍼즐, 로그라이트 |
| 플랫폼 | PC / PS5 / Switch |
| 플레이 모드 | 싱글플레이어 (메인), 비동기 멀티 (유령 기록 공유) |
| 조작 방식 | 컨트롤러 최적화, 키보드&마우스 지원 |

### 1.3 타겟 플레이어

**페르소나 A — "아트게이머" 지수 (27세, 디자이너)**
- Okami, Gris, Monument Valley처럼 아름다운 비주얼을 가진 게임을 선호
- 도전적이지 않아도 되지만 감동적이어야 함
- SNS에 게임 스크린샷을 공유하는 타입

**페르소나 B — "퍼포먼스 러너" 민혁 (22세, 대학생)**
- Mirror's Edge, Ghostrunner 같은 빠른 파쿠르에 열광
- 스피드런, 타임어택에 관심
- 유튜브에 플레이 영상을 업로드함

**페르소나 C — "스토리 탐험가" 은주 (34세, 직장인)**
- 한국 문화와 전통에 관심
- 짧은 세션(20~30분)으로 즐길 수 있는 게임 선호
- Journey, 바람의 여행자처럼 명상적 게임을 좋아함

### 1.4 핵심 차별점

1. **먹이 번지는 월드**: 플레이어 이동 경로에 따라 실시간으로 수묵화 효과가 세계에 적용됨. 같은 구간도 플레이어마다 다른 그림이 완성됨.
2. **붓글씨 전투**: 적과의 전투는 타이밍 기반 '붓 획 입력' — 올바른 필순으로 한자를 그리면 강력한 기술 발동. 획의 속도와 압력이 대미지에 영향.
3. **먹빛 스냅샷**: 스테이지 완료 시 플레이어의 이동 경로가 실제 수묵화 이미지로 저장되어 공유 가능.

### 1.5 레퍼런스 게임 분석

|------|-----------|--------------|

## 2. 핵심 게임 루프

### 2.1 코어 루프 다이어그램

```
[도시 진입] → [경로 탐색 & 파쿠르] → [장애물/적 처리]
      ↑                                        ↓
[먹빛 복원 달성]  ←  [스냅샷 생성]  ←  [구역 클리어]
      ↑                                        ↓
[서사 해금]       ←  [보상 선택]    ←  [스테이지 평가]
```

### 2.2 세션 구조

**단일 런 (20~40분)**

| 단계 | 시간 | 주요 행동 |
|------|------|-----------|
| 도시 진입 | 0~2분 | 목표 확인, 경로 선택 |
| 탐색 & 이동 | 5~15분 | 파쿠르, 숨겨진 경로 발견 |
| 전투/퍼즐 구간 | 5~10분 | 붓글씨 전투, 타이밍 퍼즐 |
| 구역 클리어 | 1~2분 | 먹빛 복원 완성, 스냅샷 |
| 보상 & 서사 | 2~3분 | 업그레이드 선택, 대화 해금 |

**메타 루프 (20~30시간 풀 플레이)**

```
런 완료 → 먹 포인트 획득 → 붓 능력 영구 해금 → 새 구역 접근 → 서사 진행
```

### 2.3 사망 & 리컨티뉴

- **사망 페널티 없음**: 체크포인트에서 즉시 재시작
- **먹 손실**: 사망 시 해당 구간에서 복원한 먹빛 50% 손실 (재도전 시 복원 가능)
- **유령 시스템**: 이전 런의 경로가 반투명 실루엣으로 표시 — 참고하거나 무시 가능

## 3. 게임 시스템

### 3.1 핵심 메카닉 — 파쿠르 이동

**기본 이동 세트**

| 액션 | 입력 | 먹 소모 | 효과 |
|------|------|---------|------|
| 달리기 | 좌스틱 | 없음 | 기본 이동, 먹빛 경량 생성 |
| 벽타기 | 달리기 + 방향 | 2/초 | 수직면 이동, 먹 궤적 생성 |
| 도약 | A/X | 없음 | 기본 점프 |
| 먹 도약 | A + A (공중) | 10 | 체공 2배, 먹빛 폭발 |
| 슬라이드 | RT + 하 | 없음 | 낮은 공간 통과 |
| 먹 대시 | LB | 15 | 0.5초 순간이동, 무적 |
| 벽 반탄 | 벽 근처 + 점프 | 없음 | 벽-벽 연속 이동 |

**파쿠르 콤보 시스템**

연속 행동 없이 멈추지 않을수록 **Flow 게이지** 상승:
- Flow 0%: 기본 이동속도
- Flow 50%: 이동속도 +20%, 먹 소모 -10%
- Flow 100%: "먹빛 초월" 상태 — 30초간 전 능력 강화, 지나간 경로에 먹빛 황금 궤적 생성

### 3.2 핵심 메카닉 — 붓글씨 전투

전투는 **타이밍 기반 한자 입력** 시스템입니다. 화면에 한자의 필순이 순서대로 표시되며, 플레이어가 올바른 타이밍에 방향 입력을 일치시킵니다.

**기술 체계**

| 한자 | 발음 | 기술 효과 | 획 수 | 난이도 |
|------|------|-----------|-------|--------|
| 火 | 화 | 전방 화염 폭발 | 4획 | ★★☆☆ |
| 水 | 수 | 빙결 장판 | 3획 | ★☆☆☆ |
| 風 | 풍 | 광역 밀어내기 | 9획 | ★★★☆ |
| 雷 | 뢰 | 연쇄 번개 | 13획 | ★★★★ |
| 滅 | 멸 | 화면 전체 공격 | 14획 | ★★★★★ |

**콤보 판정**

```
Perfect (황금 획) → Normal (먹 획) → Miss (흰 획)
  × 2.0 대미지       × 1.0 대미지     × 0 대미지 + 경직
```

### 3.3 먹(墨) 자원 경제

```
먹 수급 원천:
 - 이동 중 복원 구역 통과 → +5/초
 - 적 처치 Perfect → +20
 - 숨겨진 먹항아리 발견 → +50
 - Flow 100% 유지 → +2/초 보너스

먹 소모:
 - 특수 이동 (대시, 먹도약)
 - 전투 기술 시전
 - 구역 강제 복원 (즉각 색 채우기)

최대 먹 용량: 100 (업그레이드로 최대 200)
```

### 3.4 진행 시스템 — 붓 마스터리

런 완료 시 획득하는 **먹 크리스탈**로 영구 업그레이드:

```
[붓 강화 트리]

기동력 계열:              전투 계열:              탐색 계열:
먹 최대량 +25 (3단)      한자 판정창 +30ms (3단)  미니맵 해금
벽타기 지속 +1초 (2단)   연속기 대미지 +10% (3단)  먹항아리 레이더
먹 도약 쿨타임 -2초       5획 이상 즉시 시전       숨은 경로 힌트
```

### 4.3 스토리 — 먹빛 재생

**세계관**: 2077년, AI 재벌 연합 "SOEUL Corp"이 서울 시민들의 감성과 창의성을 데이터로 추출해 도시를 단색의 효율 기계로 만들었다. 먹(墨)의 신 '묵신(墨神)'의 마지막 화신인 플레이어 캐릭터 **이묵(李墨)**은 도시에 색과 감성을 되돌리기 위해 싸운다.

**서사 구조** (Hades 방식 — 런마다 조각 해금):
- 런 1~3: 세계관 소개, 을지로 상인들과의 만남
- 런 4~7: 묵신의 기억 파편 발견, 이묵의 정체 의문
- 런 8~12: SOEUL Corp의 목적 폭로, 동료 배신
- 런 13~18: 먹빛 복원의 대가, 자아 상실 위기
- 런 19+: 최종 선택 — 도시를 구하되 이묵은 사라지는가

```
[타이틀]
   ↓
[구역 선택 지도] ←─────────────────────────┐
   ↓                                         │
[구역 진입 연출 — 먹이 번지며 로딩]           │

   ↓                                         │
[서사 대화 해금] ──────────────────────────→ ┘
```

### 5.2 HUD 설계 — 미니멀 철학

**원칙**: HUD는 플레이어가 의식하지 않아야 한다. 필요할 때만 나타나고, 아름다워야 한다.

```
┌─────────────────────────────────────────┐
│  ◉ 묵신의 눈 (Flow 게이지)              │  ← 좌상단, 먹 번짐 원형
│                                          │
│                                          │
│                [게임플레이]              │
│                                          │
│                                          │
│  [먹 용량 바]            [타이머: 선택]  │  ← 하단, 반투명
└─────────────────────────────────────────┘
```

- **Flow 게이지**: 원형 먹 번짐 이펙트로 표현 (숫자 없음)
- **체력**: 별도 표시 없음 — 화면 가장자리 먹빛이 흐려짐
- **먹 용량**: 캐릭터 주변 광환(光環)으로 표현
- **전투 중 한자**: 화면 중앙 오버레이 (전투 외엔 표시 안 함)

### 5.3 메뉴 구조

```
타이틀 화면
├── 새 런 시작
├── 먹 마스터리 (업그레이드)
│   ├── 기동력 계열
│   ├── 전투 계열
│   └── 탐색 계열
├── 먹빛 갤러리 (스냅샷 컬렉션)
├── 세계 이야기 (해금된 서사 열람)
├── 설정
│   ├── 그래픽 (먹 품질, FPS 제한)
│   ├── 오디오 (BGM/SFX 분리, 공간음향)
│   ├── 접근성 (자막 크기, 색상 필터, 한자 힌트 표시)
│   └── 조작 (키 리매핑, 감도)

```

## 6. 아트 디렉션

### 6.1 비주얼 컨셉

**"디지털 수묵 (Digital Ink)"** — 전통 수묵화의 먹 번짐과 농담(濃淡)을 사이버펑크 3D 공간에 적용. 모든 텍스처는 먹 붓 느낌의 질감을 가지며, 파티클 이펙트는 먹물이 물에 번지는 물리 시뮬레이션 기반.

**비주얼 레이어 구조**:
1. **회색 스케치 레이어** (복원 전): 연필 스케치 느낌, 디테일 없음
2. **먹빛 복원 레이어** (복원 중): 먹이 번지며 디테일 생성
3. **색채 복원 레이어** (완전 복원): 한국 전통 단청(丹靑) 색상 적용

**레퍼런스 아트**:
- Okami (붓 필선 오브젝트)
- Gris (감정에 따른 색채 변화)
- Cuphead (선 드로잉 느낌)
- 김홍도, 정선의 진경산수화

### 6.2 색상 팔레트

**Primary Palette — 먹빛 계열**

| 이름 | 헥스 | 용도 |

### 6.4 애니메이션 가이드라인

**12 원칙 적용**

| 원칙 | 적용 방법 |
|------|-----------|
| Squash & Stretch | 착지 시 캐릭터 0.85배 스쿼시 → 0.05초 후 복귀 |
| Anticipation | 대시 직전 0.1초 반대 방향 살짝 기울기 |
| Follow Through | 벽타기 후 코트 자락 0.3초 지연 |
| Ease In/Out | 모든 UI 전환 cubic-bezier(0.4, 0, 0.2, 1) |
| Secondary Action | 이동 시 머리카락, 옷깃 독립 물리 시뮬 |

**Juice 원칙 체크리스트**

- [x] 완벽 판정 시: 화면 0.1초 freeze + 황금 먹빛 파티클 폭발
- [x] Flow 100% 달성: 배경음악 레이어 추가 + 화면 색온도 변화
- [x] 먹 복원 시: 먹이 번지는 실시간 셰이더 애니메이션 (0.5~2초)
- [x] 보스 처치: 슬로우모션 0.3초 + 거대 먹빛 폭발 → 구역 전체 복원
- [x] 스냅샷 생성: 붓질 소리 + 화선지에 번지는 연출 3초

**상태 전환 타이밍**

| 전환 | 시간 | 이징 |
|------|------|------|
| 메뉴 진입/퇴출 | 250ms | Ease-out |
| 대화창 등장 | 200ms | Spring (0.8, 0.2) |
| 구역 전환 | 800ms | 먹이 화면 전체를 덮었다가 새 구역 복원 |
| 사망 | 400ms | 먹빛 붕괴 이펙트 |
| 업그레이드 선택 | 300ms | 먹 번짐 reveal |
