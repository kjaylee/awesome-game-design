# Echo Depths — 끝없는 지하의 울림

## 1. 게임 개요

### 1.1 핵심 컨셉
**Echo Depths**는 절차적으로 생성되는 지하 던전을 탐험하는 턴제 퍼즐-액션 로그라이크 게임입니다. 게임의 핵심 차별점은 "에코 메모리(Echo Memory)" 시스템으로, 플레이어가 죽을 때마다 이전 생의 행동 패턴이 유령으로 남아 현재 플레이의 힌트와 도움을 제공합니다. Hades의 서사 반복성, The Binding of Isaac의 빌드 다양성, Sokoban의 퍼즐 요소를 결합한 설계입니다.

### 1.2 타겟 플레이어
- 연령대: 13세 이상
- 플레이 스타일: 패턴 학습 게이머, 퍼즐/로그라이크 애호가, 싱글 플레이 중심
- 플레이 시간: 런당 20~60분, 비동기 진행
- 플랫폼: PC (Steam), 콘솔 (Nintendo Switch), 모바일 (나중 포팅)

### 1.3 게임의 차별점
1. **에코 메모리 시스템**: 죽은 플레이어의 행동이 유령으로 기록되어 다음 런에서 가시화됨
2. **유산(Legacy) 메커닉**: 런 간 영구 업그레이드로 장기 진행도 제공
3. **절차적 던전 생성**: 동일한 레이아웃이 반복되지 않음, 새로운 도전 매번 제공
4. **턴제 이동 기반**: 실시간 액션이 아닌 전략적 사고 가능

## 2. 핵심 게임 루프

### 2.1 단계별 흐름
```
캐릭터 선택 → 유물/축복 선택 → 던전 진입 → 층별 탐험
→ 전투/퍼즐 해결 → 보상 수집 → 사망 또는 탈출
→ 유산 획득 → 메인 메뉴 (반복)
```

### 2.2 각 페이즈 상세

#### 1) 캐릭터 선택 페이즈
- 3개 캐릭터 클래스 중 1개 선택 (검사/마법사/도적)
- 각 캐릭터는 고유한 시작 유물 1개씩 제공
- 초기 스탯 다름

#### 2) 유물/축복 선택 페이즈
- 무작위로 제시된 3개 유물 중 1개 선택 (선택 불가능 옵션 제공)
- 축복 1개 선택 (게임 보정 요소)
- 저주 1개 랜덤 부여 (도전 요소)

#### 3) 던전 탐험 페이즈
- 턴제 이동: 플레이어 한 칸 이동 → 적 이동 → 효과 처리
- 층마다 5~10개 방이 있으며 절차적으로 생성됨
- 에코 메모리 유령: 이전 플레이어의 이동 경로가 희미한 발자국으로 표시
- 전투/상호작용: E 키로 적 또는 오브젝트와 상호작용

#### 4) 전투 페이즈
- 턴제: 플레이어 행동 → 적 행동
- 플레이어 능력 사용 (에너지 소비)
- 적 패턴 예측 가능

#### 5) 보상 수집 페이즈
- 적 처치 시 골드 또는 유물 드롭
- 보상 선택 (2~3개 중 1개 선택)

#### 6) 사망 또는 탈출
- 사망: 유산 포인트 획득 후 메인 메뉴로 귀환
- 탈출: 최하층 도달 후 탈출 시 보너스 획득

## 3. 캐릭터 시스템

### 3.1 3개 클래스

#### 1) 검사(Knight) - 균형잡힌 플레이
- **체력**: 100 | **공격력**: 8 | **방어력**: 3 | **에너지**: 80
- **고유 능력 (Ultimate)**: "회전 베기" - 인접한 모든 적에게 공격력 x1.5 피해
- **시작 유물**: "방어의 약속" (받는 피해 15% 감소)
- **플레이 스타일**: 근거리 탱크, 안정적

#### 2) 마법사(Sorcerer) - 고위험 고리턴
- **체력**: 60 | **공격력**: 5 | **마법력**: 12 | **에너지**: 120
- **고유 능력**: "메테오 스톰" - 범위 3칸 내 모든 적에게 마법력 x2 피해 (에너지 30 소비)
- **시작 유물**: "마법 재충전" (이동당 에너지 +5)
- **플레이 스타일**: 원거리 강력함, 자원 관리 중요

#### 3) 도적(Rogue) - 높은 기동성
- **체력**: 75 | **공격력**: 6 | **기동력**: 15 | **에너지**: 100
- **고유 능력**: "치명적 일격" - 다음 공격이 180% 피해 + 적을 2칸 뒤로 밀침
- **시작 유물**: "그림자 발걸음" (이동 후 1칸 추가 이동 가능, 1회/턴)
- **플레이 스타일**: 기동성 중심, 전술적 회피

### 3.2 스탯 설명

| 스탯 | 설명 | 영향 |
|------|------|------|
| 체력(HP) | 플레이어 생명력 | 0 이하 시 사망 |
| 공격력 | 근거리 타격 피해 | 검사/도적의 주 능력 |
| 마법력 | 원거리 주문 위력 | 마법사의 주 능력 |
| 방어력 | 받는 피해 감소율 | 입는 피해 = 기본피해 - 방어력 |
| 기동력 | 추가 이동 거리 | 도적의 특화 능력 |
| 에너지 | 능력 사용 자원 | 능력 사용 시 소비, 매턴 회복 |

## 5. 절차적 던전 생성

### 5.1 던전 구조
- **총 층수**: 1~5층 (최하층 도달 시 탈출 가능)
- **층당 방 개수**: 5~8개 방
- **방 크기**: 8×8 ~ 12×12 그리드

### 5.2 방 타입 분류

| 방 타입 | 특징 | 적 배치 | 보상 |
|--------|------|--------|------|
| 전투실 | 적 3~5마리 | 표준 | 골드 + 유물 |
| 보스실 | 보스 1마리 | 고위험 | 골드 x3 + 유물 |
| 퍼즐실 | 퍼즐 해결 (적 없음) | 없음 | 유물 + 경험치 |
| 보물실 | 숨겨진 방 | 약함 | 보물상자 x3 |
| 상인방 | 유물 구매 | 없음 | 자유 선택 |
| 호텔(휴식) | 체력 회복 | 없음 | 자유 회복 |
| 함정실 | 위험 장애물 | 약함 | 보상 높음 |

### 5.3 방 연결 규칙
- 각 방은 1~3개의 다른 방과 연결됨
- 선형이 아닌 분기형 구조 (플레이어 선택권 제공)
- 최소한 1개의 경로는 보스실로 통함

### 5.4 시드(Seed) 기반 재현성
- 플레이어가 시드를 입력하면 동일한 던전 재생성 가능
- 도전/공유 메커닉에 활용 (특정 시드 난제 공유)

## 7. 에코 메모리(Echo Memory) 시스템

### 7.1 개념
- 플레이어가 사망하면 그 플레이어의 마지막 10턴 동안의 이동 경로가 유령으로 기록됨
- 다음 런에서 같은 층을 방문하면 그 유령이 반투명하게 나타나 과거의 행동을 반복함
- 유령은 충돌 없음 (투명), 시각적 참고용

### 7.2 에코 표시 방식
- 유령의 이동 경로: 회색 점선으로 표시
- 유령의 최종 위치: 밝은 별 아이콘으로 표시
- 유령이 적을 피한 경로: 위험 표시 (빨간 X)

### 7.3 게임플레이 상의 장점
- 처음 방문하는 플레이어도 선배 플레이어의 경로를 참고 가능
- 어려운 퍼즐의 힌트 제공 (에코 유령이 해결한 방식 모방)
- 심리적 위안감 (혼자가 아니라는 느낌)

### 7.4 기술 구현
- 로컬 저장: 클라우드 동기화 (선택사항)
- 에코 데이터 포맷: JSON (이동 좌표 배열 + 타임스탬프)
- 보안: 익명 처리 (플레이어 이름 미노출)

## 8. 메타 진행 시스템 (런 간 업그레이드)

### 8.1 유산 포인트(Legacy Points)
- 각 런 종료 시 획득 (사망/탈출 모두 가능)
- 사망: 도달 층 × 10 + 적 처치 수 × 2
- 탈출: 도달 층 × 50 + 적 처치 수 × 3
- 누적 사용으로 영구 업그레이드 구매

### 8.2 영구 업그레이드 트리

#### Tier 1 (각 10 포인트)
- 최대 체력 +10 (모든 캐릭터)
- 기본 공격력 +2 (모든 캐릭터)
- 에너지 상한 +20 (모든 캐릭터)

#### Tier 2 (각 25 포인트)
- 새로운 시작 유물 언락 (캐릭터당 1개)
- 축복 추가 선택지 +1 (총 2개 중 1개 선택)
- 상인 할인 20% (모든 층의 상인)

#### Tier 3 (각 50 포인트)
- 새로운 캐릭터 클래스 언락 (예: 성직자, 기사 등)
- 도전 모드 언락 (특수 규칙 플레이)
- 에코 메모리 범위 확대 (이전 30턴 기록)

### 8.3 시즌 진행
- 월별 시즌 리셋 (순위 초기화)
- 시즌 별 특별 도전 (특정 빌드로만 클리어 등)
- 시즌 보상 (칭호, 스킨)

## 9. 퍼즐 메카닉

### 9.1 퍼즐 타입

#### 타입 1: 블록 슬라이드
- 그리드 상의 블록들을 이동시켜 목표 배치 달성
- 인스퍼 (Sokoban) 스타일
- 최소 이동 횟수 달성 시 보너스

#### 타입 2: 회로 연결
- 전기 회로를 배치하여 출구에 전력 공급
- 타일 회전/배치로 경로 완성
- 시간 제한 없음

#### 타입 3: 규칙 해석
- 수수께끼 또는 규칙을 읽고 답을 찾기
- 예: "빨강 + 파랑 = 보라. 초록 + ? = 노랑"
- 선택지 중 답 선택

#### 타입 4: 포탈 통과
- 색깔 포탈들을 올바른 순서로 통과
- 경로상의 함정 회피
- 최소 이동 최적화

### 9.2 퍼즐 난이도
- 쉬움: 인지 자극 낮음 (30초 내)
- 중간: 전략적 사고 필요 (1~3분)
- 어려움: 복합 로직 (5분 이상)

## 18. 결론

**Echo Depths**는 로그라이크의 반복성과 에코 메모리의 혁신적 메커닉을 결합하여, 플레이어들이 커뮤니티를 통해 성장하는 경험을 제공합니다. 절차적 생성 던전과 풍부한 빌드 다양성으로 장기적 플레이 유도하며, 메타 진행 시스템으로 모든 런이 의미있는 진전을 만듭니다. 퍼즐 요소와 턴제 전투의 조합으로 전술적 깊이를 제공하는 작품입니다.
