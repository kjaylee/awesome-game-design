# Astral Cascade — 별자리의 연쇄

## 1. 게임 개요

### 1.1 핵심 컨셉
**Astral Cascade**는 별자리 테마의 보석 스왑 매치-3 퍼즐 게임으로, 전통적인 보석 교환 메카닉에 세 가지 독창적인 차별점을 가미합니다: (1) "별자리 보너스" - 특정 모양으로 매치 시 강력한 스킬 발동, (2) "중력 변환" - 각 스테이지마다 중력 방향이 달라져 보석 낙하 방향 변화, (3) "원소 연쇄" - 5원소 상성 시스템으로 콤보 배율 증폭. 모바일 캐주얼 플레이어를 주 타겟으로 합니다.

### 1.2 타겟 플레이어
- 연령대: 7세 이상
- 플레이 스타일: 캐주얼 퍼즐 게이머, 이동 제한 선호, 소셜 플레이어
- 플레이 시간: 세션당 3~8분
- 플랫폼: 모바일 (iOS/Android), 웹 브라우저

### 1.3 게임의 차별점
1. **별자리 보너스 시스템**: 특정 패턴 매치로 별자리 완성, 강력한 스킬 발동
2. **중력 변환 메카닉**: 수직/수평/대각선 다양한 중력 방향
3. **원소 연쇄 상성**: 불/물/바람/땅/별 5원소 간 상성으로 콤보 증폭
4. **대규모 스테이지 라이브러리**: 500+ 스테이지로 장기 플레이 유도

## 2. 핵심 게임 루프

### 2.1 단계별 흐름
```
스테이지 선택 → 목표 확인 → 보석 매치 시작
→ 매치/콤보 연쇄 → 목표 달성 또는 이동 소진
→ 성공(별 획득) 또는 실패 → 보상/실패 화면
```

### 2.2 각 페이즈 상세

#### 스테이지 선택 페이즈
- 월드맵에서 플레이 가능한 스테이지 선택
- 스테이지 난이도 시각화 (별 1~3개)
- 목표 미리보기 (이동 수, 목표 보석 개수)

#### 게임플레이 페이즈
- 8×8 그리드에서 보석 2개를 스왑하여 3개 이상 매치
- 매치 된 보석 소멸, 위의 보석 낙하 (중력 영향)
- 자동 콤보 체크 및 연쇄 발동
- 이동 수 감소, 목표 진행도 업데이트

#### 목표 달성 페이즈
- 이동 수 내 모든 목표 달성 → 성공
- 이동 소진 시에도 목표 미달성 → 실패
- 성공: 별 1~3개 획득 (초과 달성 시 보너스)
- 실패: 다시 시도 (부활권 또는 대기)

## 3. 게임 메카닉 상세

### 3.1 그리드 & 매치
- **그리드 크기**: 8×8 (64개 셀)
- **기본 보석 5원소**: 불(빨강), 물(파랑), 바람(초록), 땅(노랑), 별(보라)
- **매치 규칙**: 같은 색 보석 3개 이상 일렬 배치 시 소멸
- **이동 제한**: 스테이지마다 15~25 이동 제한

### 3.2 5원소 체계

#### 불(Fire) - 빨강색
- **특징**: 가장 공격적, 큰 피해
- **상성**: 바람 극복 (방어 무시 +20%)
- **약점**: 물 (피해 -30%)

#### 물(Water) - 파랑색
- **특징**: 방어적, 부드러운 피해
- **상성**: 불 극복 (피해 +30%)
- **약점**: 땅 (흡수됨, 피해 없음)

#### 바람(Wind) - 초록색
- **특징**: 빠른 연쇄, 광범위 효과
- **상성**: 땅 극복 (범위 2배)
- **약점**: 별 (방해받음, 매치 불가)

#### 땅(Earth) - 노랑색
- **특징**: 느리지만 안정적, 방어
- **상성**: 물 극복 (공격력 +50%)
- **약점**: 바람 (흩어짐, 효율 -50%)

#### 별(Star) - 보라색
- **특징**: 신비로운, 특수 효과
- **상성**: 바람 극복 (무시통과)
- **약점**: 불 (소멸)

### 3.3 원소 연쇄(Element Chain) 시스템

#### 연쇄 보너스 규칙
1. 같은 색 3개 매치: 기본 배율 1.0x
2. 4개 매치: 배율 1.5x
3. 5개 이상 매치: 배율 2.0x
4. **원소 상성 활성화**: 
   - 불-바람 조합: 배율 1.2x (최종)
   - 물-불 조합: 배율 1.3x (최종)
   - 바람-땅 조합: 배율 1.25x (최종)
   - 땅-물 조합: 배율 1.4x (최종)
   - 별-바람 조합: 배율 1.5x (최종)

#### 콤보 단계별 배율
| 콤보 수 | 배율 | 누적 |
|--------|------|------|
| 1번째 | 1.0x | 1.0x |
| 2번째 | 1.1x | 1.1x |
| 3번째 | 1.2x | 1.3x |
| 4번째 | 1.3x | 1.7x |
| 5번째 이상 | 1.5x | 2.55x+ |

### 3.4 특수 보석 6종

#### 1) 폭탄(Bomb) 보석
- 매치 시 인접 8칸 모든 보석 소멸
- 일반 보석 4개 직렬 매치 시 자동 생성
- 아이콘: 검은 구체에 노랑 X 표시

#### 2) 번개(Lightning) 보석
- 매치 시 상하 일렬 모든 보석 소멸 + 가로 1줄 추가 소멸
- 같은 색 5개 L자형 매치 시 생성
- 아이콘: 별 모양 번개

#### 3) 무지개(Rainbow) 보석
- 매치 시 모든 같은 색 보석 소멸
- 별 보석 5개 일렬 매치 시 생성
- 아이콘: 밝은 무지개 색상

#### 4) 얼음(Frozen) 보석
- 2번 매치해야 소멸 (첫 매치 후 얼음 상태)
- 얼음 상태일 때 인접 보석 매치도 얼음화 확산
- 아이콘: 파란색 투명한 얼음 결정체

#### 5) 체리(Cherry) 보석
- 특수한 목표 (특정 스테이지에서만 출현)
- 매치로 소멸 불가, 폭탄/번개/무지개로만 제거 가능
- 포인트 획득에만 사용

#### 6) 상자(Box) 보석
- 특정 아이템 포함
- 3번 타격되어야 소멸
- 각 타격마다 내부 아이템 효과 발동

### 3.6 중력 변환(Gravity Shift) 메카닉

#### 중력 방향 4가지

| 방향 | 효과 | 보석 낙하 | 난이도 |
|------|------|---------|--------|
| 아래(Normal) | 표준 중력 | 아래로 | 쉬움 |
| 위(Inverse) | 역방향 중력 | 위로 | 중간 |
| 왼쪽(Left) | 수평 중력 | 좌측으로 | 어려움 |
| 오른쪽(Right) | 수평 중력 | 우측으로 | 어려움 |

#### 중력 변환 방식
- **고정 중력**: 스테이지 시작 시 정해진 중력만 사용
- **변환 중력**: 특정 이동 후 중력 자동 전환 (예: 10이동마다)
- **선택 중력**: 플레이어가 선택하여 전환 가능 (제한 횟수)

### 3.7 스테이지 목표 시스템

#### 목표 타입 5가지

| 목표 | 설명 | 예시 |
|------|------|------|
| 점수 목표 | 특정 포인트 이상 획득 | "50,000 점 달성" |
| 보석 수거 | 특정 색 보석 제거 | "빨간 보석 20개 제거" |
| 적 처치 | 보드 하단 적 모두 제거 | "적 3마리 제거" |
| 아이템 수집 | 특정 아이템 수거 | "열쇠 5개 수집" |
| 시간 제한 | 제한 시간 내 달성 | "60초 내 500점" |

#### 난이도 조정
- **1별**: 목표의 60% 달성
- **2별**: 목표의 80% 달성
- **3별**: 목표의 100% 달성 + 이동 수 초과 없음

## 4. 스테이지 설계 방법론

### 4.1 총 500 스테이지 구조

#### World 1: 별의 정원 (스테이지 1-50)
- 난이도: 1~2성
- 주제: 초급 튜토리얼
- 특징: 단순 매치만 사용, 보너스 보석 희소

#### World 2: 은하 비행 (스테이지 51-150)
- 난이도: 2~3성
- 주제: 특수 보석 도입
- 특징: 폭탄/번개 보석 등장, 기본 별자리 5개

#### World 3: 우주 심연 (스테이지 151-300)
- 난이도: 3~4성
- 주제: 중력 변환 도입
- 특징: 중력 변환 메카닉, 모든 별자리 소개

#### World 4: 혜성 추적 (스테이지 301-450)
- 난이도: 4~5성
- 주제: 복합 메카닉
- 특징: 모든 요소 결합, 고도 전략 필요

#### World 5: 별의 탄생 (스테이지 451-500)
- 난이도: 5성 이상
- 주제: 최종 챌린지
- 특징: 극한 난이도, 엘리트 플레이어 대상

### 4.2 스테이지 생성 알고리즘
- **변수**: 이동 수, 그리드 배치 패턴, 중력 방향, 목표 조합
- **난이도 계산**: (이동 수 + 장애물 수) × 목표 다중도 = 예상 난이도
- **재밸런싱**: 플레이어 통과율 50~70% 목표

## 8. 프로그레션 & 리워드

### 8.1 플레이어 레벨
- 경험치는 스테이지 완료로 획득 (1스테이지 = 10 EXP)

### 8.2 수집 요소
- **배지 수집**: 특정 조건 달성 (별자리별 1개, 총 12개)
- **타이틀 언락**: 특정 스테이지 클리어 (예: "별의 정복자", "우주 마법사")
- **스킨 수집**: 모든 테마 스킨 (로그인 도표)

### 8.3 일일 보상
- **로그인 보상**: 일일 골드 50 + 보너스 (7일 주기)
- **일일 과제**: 3개 과제 (각 보상 루비 5, 일부 광고)
- **시간 보상**: 4시간마다 포인트 획득 (최대 5회)

## 11. 게임 밸런싱 기준

### 11.1 난이도 곡선
- 스테이지 1~50: 승률 95% (튜토리얼)
- 스테이지 51~150: 승률 80% (중급)
- 스테이지 151~300: 승률 60% (고급)
- 스테이지 301~450: 승률 40% (어려움)
- 스테이지 451~500: 승률 15% (극난이도)

### 11.2 이동 수 설정
- 쉬운 스테이지: 25 이동
- 중간 스테이지: 20 이동
- 어려운 스테이지: 15 이동
- 극난이도: 12 이동 이하

### 11.3 보석 드롭율
- 폭탄 생성: 5% (매 매치)
- 번개 생성: 3%
- 무지개 생성: 2%
- 얼음 상태: 4%
