# Nano Swarm — 최후의 나노봇
## 게임 디자인 문서 v1.0

---

## 1. 게임 개요

### 1.1 제목 및 장르
- **제목**: Nano Swarm — 최후의 나노봇
- **장르**: Battle Royale / Last Stand
- **플랫폼**: 웹 기반 (HTML5 Canvas + WebSocket)
- **멀티플레이**: 100인 동시 플레이
- **게임 시간**: 약 3분 (싱글 세션)
- **관점**: 2D 탑다운 뷰

### 1.2 게임 컨셉
100개의 마이크로 나노봇들이 수축하는 경기장에 투입되어 생존하고 상대를 격멸하는 배틀로얄 게임이다. 기존 배틀로얄의 획일적 전투에서 벗어나 "군집 행동", "전자기파 지형", "AI 유령팀" 세 가지 혁신적 메카닉을 도입하여 매 경기마다 독특한 전술과 협력의 순간을 창출한다.

## 2. 차별점 및 혁신 메카닉

### 2.1 군집 행동 (Swarm Behavior)
#### 개념
동일한 팀(같은 색)에 속한 나노봇들이 일정 거리 이내에 접근하면 자동으로 군집 형성, 물리적·능력적 강화가 일어난다.

#### 상세 규칙
- **반경**: 약 1.5개 타일(약 40px)
- **최소 개수**: 3개 이상의 나노봇 동시 접근 시 군집 형성
- **비주얼**: 개별 나노봇 주변에 에너지 파장 이펙트, 중앙에 모조 핵심부 표시
- **보너스 효과**:
  - 공격력: +15% (나노봇당 +5%)
  - 방어력: +10% (나노봇당 +3%)
  - 이동 속도: -5% (밀집 형태로 인한 무게 증가)
  - 시야: +20% (집단 감지)

### 2.2 전자기파 지형 (Electromagnetic Fields)
#### 개념
경기장 곳곳에 랜덤으로 생성되는 전자기 필드가 특정 무기의 성능을 강화하거나 약화시킨다.

#### 필드 타입 및 효과
1. **양극 필드** (파란색)
   - 강화 무기: 플라즈마 건, 전자 검, 펄스 라이플
   - 강화율: +30% 데미지

2. **음극 필드** (빨간색)
   - 강화 무기: 열에너지 무기, 방사선 건, 화염 방사기
   - 강화율: +25% 데미지

3. **중성 필드** (초록색)
   - 강화 무기: 기계식 무기, 킬로 건, 피어싱 라이플
   - 강화율: +20% 데미지

4. **혼합 필드** (보라색, 드물게 나타남)
   - 모든 무기 +10% 데미지

### 2.3 AI 유령팀 (Ghost Squad Revival)
#### 개념
탈락한 플레이어가 AI로 부활하여 복수 기회를 얻는다. 게임 흥미도를 높이고 플레이어의 몰입감을 연장한다.

#### 메카닉 상세
- **탈락 후 AI 부활 조건**:
  - 처치 후 2초 대기 (복수 기회 선택 팝업)
  - "유령팀 참여"를 선택하면 AI로 4라운드 더 게임 지속

- **유령팀 AI의 특성**:
  - 시야: 180도, 범위 1.5타일
  - 공격성: 높음 (자신을 처치한 나노봇에게 우선 공격)
  - 체력: 50% 감소

## 3. 핵심 게임 루프

### 3.1 매크로 루프 (전체 경기 흐름)
```
로비 → 로딩 → 낙하 (10초) → 전투 (2분 50초) → 결과 → 로비
```

### 3.2 페이즈별 설명

#### 로비 페이즈 (0~20초)
- 플레이어 100명 모집 또는 대기 (최대 2분)
- 팀 배정 (무작위 또는 선택)
- 나노봇 클래스 선택 (5초)
- 스킨/이모트 확인

#### 낙하 페이즈 (20~30초)
- 모든 플레이어 맵 중앙 상단에서 낙하 시작
- 낙하 속도: 조절 가능 (기본 1타일/프레임)
- 좌측/우측 화살표로 방향 조절 가능

#### 전투 페이즈 (30초~170초)
- 착지 후 근처 무기/아이템 수집
- 수축 영역 축소 (5단계, 각 20초 간격)
- 플레이어 수 감소 (100 → 50 → 25 → 12 → 6 → 1)

#### 결과 페이즈 (170~180초)
- 1위: 500 포인트 + 보너스 (처치수×10)
- 2~3위: 250포인트
- 4~10위: 100포인트
- 11~100위: 20포인트

## 4. 나노봇 시스템

### 4.1 5개 클래스 상세 명세

#### 4.1.1 돌격 (Assault)
- **최대 체력**: 100
- **이동 속도**: 1.2타일/초
- **시야 범위**: 2.5타일
- **주무기**: 나노 검 (근거리, 20 데미지)
- **특수 능력 1**: '돌진' - 1.5타일 거리 이동 (쿨타임 3초)
- **특수 능력 2**: '광선 참격' - 전방 180도 범위, 20 데미지 (쿨타임 5초)
- **궁극기**: '나노 폭탄' - 반경 3타일 내 전원 60 데미지 (쿨타임 15초)

#### 4.1.2 저격 (Sniper)
- **최대 체력**: 60
- **이동 속도**: 1.0타일/초
- **시야 범위**: 4.0타일
- **주무기**: 플라즈마 라이플 (원거리, 25 데미지)
- **특수 능력 1**: '스코프 조준' - 시야 범위 +1.5타일, 명중률 +30% (10초 지속)
- **특수 능력 2**: '초정밀 사격' - 데미지 +50%, 단발 (쿨타임 5초)
- **궁극기**: '포화 사격' - 3개 탄환 연발, 각 35 데미지 (쿨타임 12초)

#### 4.1.3 지원 (Support)
- **최대 체력**: 75
- **이동 속도**: 0.95타일/초
- **시야 범위**: 2.0타일
- **주무기**: 이온 건 (중거리, 15 데미지)
- **특수 능력 1**: '치유파' - 반경 2타일 아군 생명력 15 회복 (쿨타임 4초)
- **특수 능력 2**: '강화 필드' - 반경 2타일 아군 방어력 +20% (8초 지속)
- **궁극기**: '부활 펄스' - 전사한 아군 1명 부활 (쿨타임 20초)

#### 4.1.4 방어 (Tank)
- **최대 체력**: 150
- **이동 속도**: 0.8타일/초
- **주무기**: 핸머 (근거리, 18 데미지)
- **특수 능력 1**: '쉴드 생성' - 흡수 체력 40 생성 (12초 지속)
- **특수 능력 2**: '도발' - 반경 3타일 내 적 주의 전환 (4초 지속)
- **궁극기**: '나노 요새' - 제자리 고정, 대미지 50% 감소 (8초 지속)

#### 4.1.5 해커 (Hacker)
- **최대 체력**: 70
- **이동 속도**: 1.1타일/초
- **주무기**: 바이러스 건 (중거리, 16 데미지)
- **특수 능력 1**: '시스템 침투' - 적 1명 이동 불가 (3초, 쿨타임 5초)
- **특수 능력 2**: '감지 해킹' - 반경 4타일 내 모든 적 위치 표시 (5초 지속)
- **궁극기**: '전자 폭발' - 반경 2.5타일 내 적들 DoT 부여 (초당 5 데미지)

## 7. 멀티플레이 네트워크 아키텍처

### 7.1 기술 스택
- **프론트엔드**: HTML5 Canvas (2D 렌더링)
- **네트워크**: WebSocket (실시간 양방향 통신)
- **백엔드**: Node.js + Express
- **데이터베이스**: MongoDB (플레이어 통계)
- **호스팅**: AWS EC2 (게임 서버)

### 7.2 네트워크 프로토콜
#### 클라이언트 → 서버 메시지 (30ms 주기)
```json
{
  "type": "player_update",
  "player_id": "abc123",
  "position": { "x": 100, "y": 200 },
  "rotation": 45,
  "action": "attack"
}
```

#### 서버 → 클라이언트 메시지 (30ms 주기)
```json
{
  "type": "world_state",
  "players": [
    { "id": "abc123", "position": { "x": 100, "y": 200 }, "health": 85 }
  ]
}
```
