# 신규 게임 기획서 컬렉션

본 디렉토리는 세계 최고 수준의 게임 기획으로 작성된 5개의 신규 게임 기획서를 포함합니다.
각 기획서는 실제 개발에 착수 가능한 수준의 상세한 내용을 담고 있습니다.

---

## 1. Void Watch — 차원 균열 방어
**파일**: `tower-defense-voidwatch.md`  
**메카닉**: Tower Defense  
**특징**: 역장 연결 시스템, 동적 그리드, 8종 타워, 30웨이브

### 핵심 요소
- **차별점**: "역장 연결(Force Field Link)" - 인접 타워들 사이의 시너지 효과
- **게임 루프**: 웨이브 배치 → 자동 전투 → 업그레이드
- **콘텐츠**: 타워 8종, 적 10종, 보스 6종, 웨이브 30개
- **수익화**: 시즌 패스, 스킨, 배틀패스, 광고

### 파일 정보
- 크기: 20KB
- 섹션 수: 93개
- 개발 기간: 8주 (MVP 기준)

---

## 2. Echo Depths — 끝없는 지하의 울림
**파일**: `roguelike-echo-depths.md`  
**메카닉**: Roguelike / Roguelite  
**특징**: 에코 메모리 시스템, 절차적 던전, 빌드 다양성

### 핵심 요소
- **차별점**: "에코 메모리" - 죽은 플레이어의 행동이 유령으로 남아 힌트 제공
- **게임 루프**: 던전 탐험 → 전투/퍼즐 → 보상 → 사망 → 유산 획득
- **콘텐츠**: 3개 캐릭터, 유물 30개, 적 10종, 보스 5종, 퍼즐 4종
- **메타 시스템**: 유산 포인트, 영구 업그레이드, 메타 진행

### 파일 정보
- 크기: 20KB
- 섹션 수: 90개
- 개발 기간: 11주 (MVP 기준)

---

## 3. Astral Cascade — 별자리의 연쇄
**파일**: `match3-astral-cascade.md`  
**메카닉**: Match-3 / Gem Swap  
**특징**: 별자리 보너스, 중력 변환, 원소 연쇄 시스템

### 핵심 요소
- **차별점**: (1) 별자리 보너스 (2) 중력 방향 변환 (3) 원소 상성 시스템
- **게임 루프**: 스테이지 선택 → 보석 매치 → 콤보 연쇄 → 목표 달성
- **콘텐츠**: 5원소, 특수 보석 6종, 별자리 패턴 12개, 500+ 스테이지
- **수익화**: Lives 시스템, 부스터, 배틀패스, 스킨

### 파일 정보
- 크기: 16KB
- 섹션 수: 85개
- 개발 기간: 8주 (MVP 기준)

---

## 4. Rune Forge — 룬의 대장간
**파일**: `deckbuild-runeforge.md`  
**메카닉**: Deck Building / Card Roguelite  
**특징**: 룬 융합 시스템, 모바일 최적화, Intent 시스템

### 핵심 요소
- **차별점**: "룬 융합" - 2장 카드 조합으로 새로운 하이브리드 카드 생성
- **게임 루프**: 캐릭터 선택 → 탐험 맵 → 전투 → 카드 획득 → 융합
- **콘텐츠**: 5개 캐릭터, 카드 100개, 유물 50개, 이벤트 30개, 보스 5종
- **조합 시스템**: 1000+ 가능한 카드 조합

### 파일 정보
- 크기: 20KB
- 섹션 수: 81개
- 개발 기간: 11주 (MVP 기준)

---

## 5. Neon District — 빛나는 도시의 설계자
**파일**: `citybuilder-neon-district.md`  
**메카닉**: City Builder / Casual Tycoon  
**특징**: 야간 경제, 주민 AI, 해킹 방어 이벤트

### 핵심 요소
- **차별점**: (1) 야간 경제 (2) 주민 AI (3) 해킹 이벤트 방어
- **게임 루프**: 도시 설계 → 시간 경과 → 수익 창출 → 확장
- **콘텐츠**: 건물 50종 (주거/상업/산업/인프라/공공서비스/특수)
- **동적 시스템**: 낮/밤 사이클, 주민 행동 AI, 해킹 복구 메커닉

### 파일 정보
- 크기: 16KB
- 섹션 수: 78개
- 개발 기간: 9주 (MVP 기준)
