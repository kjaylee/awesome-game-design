# Neon District — 빛나는 도시의 설계자

## 1. 게임 개요

### 1.1 핵심 컨셉
**Neon District**는 2077년 사이버펑크 도시를 블록 단위로 설계하고 운영하는 캐주얼 시티 빌더 게임입니다. 플레이어는 20×20 이소메트릭 그리드에서 건물 50종을 배치하고, 독창적인 세 가지 메커닉을 통해 도시를 발전시킵니다: (1) "야간 경제" - 낮/밤 사이클에 따라 건물 수익이 달라짐 (클럽은 밤, 공장은 낮), (2) "주민 AI" - 각 주민이 일/소비/수면 패턴을 가지고 자율 이동, (3) "해킹 이벤트" - 랜덤 사이버 공격 발생, 방어 시스템 구축으로 대응. Casual Tycoon 게이머를 주 타겟으로 합니다.

### 1.2 타겟 플레이어
- 연령대: 13세 이상
- 플레이 스타일: 도시 건설 애호가, 경영 시뮬레이션 게이머, 한가한 진행 선호
- 플레이 시간: 일일 15~30분 (비동기 진행)
- 플랫폼: 모바일 (iOS/Android), 웹 브라우저

### 1.3 게임의 차별점
1. **야간 경제 시스템**: 낮/밤 사이클로 건물 수익 차등화
2. **주민 AI 시스템**: 각 주민이 독립적인 일정과 행동 패턴 소유
3. **해킹 방어 이벤트**: 동적 위협 요소로 전략적 도시설계 필요
4. **이소메트릭 그래픽**: 입체적이고 매력적인 시각 표현

## 2. 핵심 게임 루프

### 2.1 단계별 흐름
```
게임 시작 → 시간 경과 (낮/밤 자동 진행)
→ 주민 이동 & 활동 → 건물 수익 발생
→ 해킹 이벤트 발생 (랜덤) → 플레이어 대응
→ 자원 적립 → 새 건물 구매/배치
→ 도시 확장 → 다음 사이클 (반복)
```

### 2.2 각 페이즈 상세

#### 시간 사이클
- **낮(06:00~18:00)**: 12시간 = 게임 1분 (가속)
- **밤(18:00~06:00)**: 12시간 = 게임 1분 (가속)
- **시간 흐름**: 플레이 중 자동 진행, 일시정지 가능

#### 주민 행동 페이즈
- 아침: 주민 일어남, 직장으로 출근
- 낮: 직장 업무, 점심 식사, 쇼핑
- 저녁: 귀가, 취미 활동 (클럽/카페/영화)
- 밤: 수면

#### 수익 발생 페이즈
- **낮**: 공장, 사무실, 학교 수익 발생
- **밤**: 클럽, 바, 카지노 수익 발생
- **24시간 수익**: 주거지, 식당, 병원 지속 수익
- 수익 = 건물 등급 × 주민 만족도 × 시간 배율

#### 해킹 이벤트 페이즈
- 확률: 분당 약 5% (설정 가능)
- 해킹 대상: 무작위 건물 또는 시스템
- 피해: 건물 마비 또는 수익 손실
- 대응: 방어 시스템 활성화 또는 피해 수용

#### 도시 확장 페이즈
- 자원 충분 시 새 건물 구매 가능
- 건물 배치 선택 (그리드 상 자유)
- 건물 연결 및 네트워크 형성

## 4. 경제 시스템

### 4.1 자원 3가지

#### 골드 (화폐)
- **획득**: 건물 수익, 광고, 세금
- **사용**: 건물 구매, 업그레이드, 해킹 복구
- **초기값**: 5,000

#### 에너지 (전력)
- **획득**: 발전소, 태양열 패널, 전력망 연결
- **사용**: 건물 운영 (높은 효율 건물 많이 소비)
- **저장**: 배터리 시스템 (선택)

#### 데이터 (정보)
- **획득**: 통신탑, AI 센터, 연구 기관
- **사용**: 해킹 방어, 최적화, 신기술 언락
- **특징**: 선택적 자원 (고급 플레이어용)

### 4.2 수익 공식
```
일일 수익 = Σ(건물등급 × 만족도 × 시간배율 × 보정치)
```

- **낮 시간 배율**: 공장/사무실 1.0x, 상업 0.5x
- **밤 시간 배율**: 클럽/바 1.0x, 공장 0.3x
- **만족도 보정**: -50% ~ +50% (주민 만족도에 따라)
- **오염 페널티**: -5% ~ -30% (건물 오염도에 따라)

### 4.3 세금 시스템
- **소득세**: 일일 수익의 10% (자동 징수)
- **재산세**: 건물 가치의 0.5% (일일)
- **환경세**: 오염도 높음 시 추가 세금
- **전력세**: 전력 사용량의 5%

## 5. 주민(Citizen) AI 시스템

### 5.1 주민 행동 패턴

#### 아침 (06:00~09:00)
1. 주거지에서 깨어남
2. 아침 식사 (식당, 카페 방문)
3. 직장으로 출근 (자동차/대중교통)

#### 낮 (09:00~12:00)
1. 직장에서 근무 (사무실, 공장, 가게)
2. 점심 시간 (식당, 카페)
3. 계속 근무

#### 오후 (12:00~18:00)
1. 근무 계속
2. 간식/쇼핑 (상점 방문)
3. 퇴근 준비

#### 저녁 (18:00~21:00)
1. 퇴근, 귀가 또는 여가지역 방문
2. 저녁 식사 (식당, 카페)
3. 오락 활동 (클럽, 영화관, 공원)

#### 밤 (21:00~06:00)
1. 집으로 귀가
2. 충전/휴식
3. 수면

### 5.2 주민 만족도
- **기본값**: 50 (중립)
- **증가 요인**: (+5~10 각각)
  - 근처 공원 있음
  - 근처 식당 있음
  - 근처 오락시설 있음
  - 저 오염도
- **감소 요인**: (-5~10 각각)
  - 높은 오염도
  - 원거리 직장
  - 과밀 건물
  - 안전 문제 (범죄/화재)

### 5.3 주민 행동 동기
- **자동 경로 설정**: A* 알고리즘 (최단 경로)
- **취향 반영**: 일부 주민은 특정 건물 선호 (개인화)
- **상호작용**: 주민 간 만남 (우호도 증가)

## 6. 해킹 이벤트 시스템

### 6.1 해킹 타입 5가지

#### 타입 1: 데이터 유출
- **대상**: 모든 건물
- **피해**: 1시간 동안 해당 건물 수익 -50%
- **해결**: 통신탑이나 사이버보안센터로 복구 (5분)

#### 타입 2: 범인코드
- **대상**: 카지노, 은행 시뮬레이션 건물
- **피해**: 골드 손실 (건물 수익의 2배)
- **해결**: 경찰청 출동 (10분) 또는 수동 복구 (골드 지불)

#### 타입 3: 에너지 그리드 공격
- **대상**: 전력 공급망 전체
- **피해**: 모든 건물 에너지 -50% (30분)
- **해결**: 발전소 재부팅 (수동) 또는 자동 복구 (5분)

#### 타입 4: 신원 사기
- **대상**: 주거지역
- **피해**: 주민 만족도 -20%, 이주 위험
- **해결**: 경찰청 및 통신탑 협력

#### 타입 5: 시스템 마비
- **대상**: AI 관리 센터 (최고급 건물)
- **피해**: 도시 전체 효율 -30% (1시간)
- **해결**: 수동 복구만 가능 (매우 어려움)

### 6.2 해킹 확률
- **기본 확률**: 분당 5% (시간이 빠를수록 높음)
- **해킹 방어 시스템 증가**:
  - 통신탑: -5%
  - 방화벽: -30%
  - 사이버보안센터: -50%
  - 합산: 최대 -85% (0이 되지는 않음)

### 6.3 복구 전략
- **선제적**: 강력한 방어 시스템 구축 (비용 높음)
- **반응적**: 해킹 발생 시 빠르게 대응 (스킬 필요)
- **하이브리드**: 일부 방어 + 빠른 복구

## 9. MVP 개발 우선순위

### Phase 1: 핵심 게임플레이 (4주)
1. 20×20 이소메트릭 그리드 렌더링

6. 세이브/로드 시스템

### Phase 2: 확장 & AI (3주)

5. 베타 테스트 밸런싱

## 10. 기술 스택

### 10.1 게임 엔진
- **렌더링**: PixiJS (이소메트릭 2D)
- **언어**: TypeScript
- **물리/AI**: 커스텀 구현

### 10.2 아키텍처
- **건물 데이터**: JSON (배치 및 속성)
- **주민 데이터**: 객체 배열 (위치, 일정, 만족도)
- **저장**: IndexedDB (로컬) + Firebase (클라우드 선택)

### 10.3 개발 도구
- **빌드**: Webpack
- **UI**: React (메뉴, HUD)
- **테스트**: Jest

- 저가: 500~1,500 (기본 건물)
- 중가: 1,500~3,000 (확장 건물)
