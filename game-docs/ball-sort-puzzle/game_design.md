# Ball Sort Puzzle - Game Design Document

## 1. 게임 컨셉 및 비전

### 1.1 게임 컨셉
**Ball Sort Puzzle**은 색상별로 공을 정렬하는 논리 퍼즐 게임입니다. 플레이어는 제한된 공간 내에서 맨 위의 공만 이동시킬 수 있다는 단순한 규칙 속에서 모든 공을 색상별로 분류하는 문제를 풀어나갑니다.

### 1.2 게임의 비전
- **핵심 가치**: "단순한 규칙, 깊이 있는 전략"
- **타겟 플레이어**: 논리 퍼즐을 즐기는 모든 연령층 (10-60세)
- **플레이 방식**: 스마트폰에서 손가락 터치로 직관적으로 즐길 수 있음
- **플레이 시간**: 게임당 5-20분 (난이도에 따라 다름)
- **장기 목표**: 모든 난이도 클리어, 최고 점수 달성

### 1.3 슬로건
**"공을 색깔별로 정렬하라. 간단한 규칙, 끝없는 도전\!"**

## 2. 메카닉 분류

### 2.1 주 메카닉: Puzzle / Sort & Stack

**퍼즐 요소 (Puzzle)**:
- 주어진 상황에서 규칙을 따라 문제 해결
- 논리적 사고와 공간 지각 능력 필요
- 최적 경로 찾기 (이동 횟수 최소화)

**정렬 요소 (Sort)**:
- 공들을 색상별로 분류하는 과정
- 출발 상태: 무작위로 섞인 공들
- 목표 상태: 각 색상별로 분류된 상태

**스택 요소 (Stack)**:
- LIFO (Last In First Out) 데이터 구조
- 튜브 상단의 공만 이동 가능
- 이동 순서가 중요한 핵심 메커니즘

### 2.2 게임 메커니즘의 핵심

1. **제약 조건**: 맨 위의 공만 이동 가능 (아래 공은 봉인됨)
2. **매칭 규칙**: 같은 색 공 위에만 쌓을 수 있음
3. **공간 제약**: 튜브 용량 제한 (보통 4개)
4. **추가 공간**: 해결을 위해 빈 튜브 2개 제공

## 3. 핵심 재미 요소

### 3.1 문제 해결의 쾌감
- **"Aha\!" 모멘트**: 막혔던 상황을 갑자기 풀 방법을 발견했을 때의 뿌듯함
- **최적화 욕구**: 더 적은 이동으로 푸는 방법 찾기
- **성취감**: 순간순간 공들이 색깔별로 정렬되는 모습이 주는 시각적 만족감

### 3.2 직관적 조작
- **터치 인터페이스**: 공을 선택하고 목표 튜브로 끌어놓는 직관적 조작
- **즉시 피드백**: 이동 불가능한 경우 즉시 피드백 (비트 진동)
- **학습 곡선**: 첫 게임부터 규칙을 쉽게 이해

### 3.3 점진적 난이도 상승
- **Easy**: 2-3색만으로 10분 내 클리어 가능
- **Normal**: 4-5색으로 전략적 사고 필요
- **Hard/Expert**: 6+색으로 최고의 집중력 요구

### 3.4 도구의 활용 전략
- **힌트 선택**: 3회라는 제한 속에서 언제 사용할지 결정
- **셔플 기회**: 막힌 상황에서의 돌파구
- **되돌리기**: 실수 복구 기회 (5회까지)

### 3.5 시각적 만족도
- **색상 표현**: 라디알 그라디언트로 입체감 있는 공 표현
- **애니메이션**: 공이 이동할 때의 부드러운 애니메이션
- **완성 효과**: 튜브가 완성될 때의 광택 이펙트와 점수 플로팅

## 4. 게임플레이 루프

### 4.1 단일 게임 루프 (5-20분)

```
게임 시작 (새 게임 또는 계속하기)
  ↓
현재 배치 분석 및 전략 수립
  ↓
(반복)
  이동 가능한 공 찾기
    ↓
  공 선택 및 목표 튜브 선택
    ↓
  이동 실행 (애니메이션)
    ↓
  점수 추가, 완성 튜브 확인
    ↓
  필요 시 도구 사용 (힌트, 셔플, 되돌리기)
↓
게임 종료 (승리 또는 패배)
  ↓
결과 확인 및 점수 기록
  ↓
다음 레벨 또는 메뉴로
```

### 4.2 세션 루프 (30분 이상)

```
여러 게임 연속 진행
  ↓
난이도별 레벨 해금
  ↓
각 난이도별 최고 점수 갱신 시도
  ↓
새로운 색상 조합 경험
  ↓
세션 종료 (저장)
```

### 4.3 장기 루프 (주 단위)

```
일일 챌린지 도전 (선택사항)
  ↓
리더보드 순위 갱신 시도
  ↓
모든 난이도 마스터 목표
  ↓
개인 최고 기록 갱신 도전
  ↓
친구와 점수 비교 (선택적)
```

## 5. 난이도 설계

### 5.1 게임 난이도 단계

| 난이도 | 색상 수 | 최적 이동 | 권장 시간 | 대상 플레이어 |
|--------|---------|---------|---------|----------|
| **Easy** | 2-3색 | 3-8이동 | 5-10분 | 입문자, 어린이 |
| **Normal** | 4-5색 | 8-15이동 | 10-15분 | 경험 있는 플레이어 |
| **Hard** | 6-7색 | 15-25이동 | 15-20분 | 숙련자 |
| **Expert** | 8-12색 | 25+이동 | 20분 이상 | 마스터 플레이어 |

### 5.2 난이도 조절 메커니즘

- **색상 복잡도**: 색상 수 증가 → 경로 탐색 어려움
- **튜브 용량**: 추가 제약 조건 (용량을 줄임)
- **이동 제한**: 되돌리기 횟수 감소
- **점수 배수**: 어려울수록 더 높은 보상

### 5.3 실패 방지

- **도구 충분**: 3회 힌트, 1회 셔플로 대부분 해결 가능
- **도움 시스템**: 막혔을 때 "힌트 사용?" 제안
- **되돌리기**: 5회까지 복구 가능
- **재시작 용이**: "포기" 버튼으로 언제든 새 게임

## 6. 수익화 방안

### 6.1 무료 게임 모델

Ball Sort Puzzle은 **무료 게임**으로 설계되었으나, 선택적 수익화 옵션 제공:

#### A. 광고 기반 (선택적)
- **게임 오버 광고**: 게임 실패 시 광고 시청 → "재시도" 기회 (1회/게임)
- **도구 광고**: 도구 소진 시 광고 시청 → 도구 1회 충전
- **보상 광고**: 일일 보너스 포인트 광고 시청 → 획득

#### B. 구독 모델 (프리미엄)
- **Ball Sort Pro**: 월 2,900원
  - 광고 완전 제거
  - 무제한 힌트 및 셔플
  - 일일 특별 챌린지 추가
  - 통계 분석 및 성과 추적
  
#### C. DLC (확장 컨텐츠)
- **색상 팩**: 5,900원
  - 특수 색상 추가 (무지개, 야광 등)
  - 테마 변경 (우주, 수중 등)

#### D. 소량 과금 (IAP)
- **도구 충전**: 100원~
  - 힌트 3회 = 490원
  - 셔플 1회 = 290원
  - 되돌리기 5회 = 390원

### 6.2 수익화 철학

- **핵심 게임플레이 무료**: 광고나 과금 없이 모든 난이도 클리어 가능
- **편의성 판매**: 과금은 시간 절약과 편의성만 제공
- **공정한 경쟁**: 과금 플레이어가 실력상 우위를 갖지 않음
- **거슬리지 않는 광고**: 보상형 광고만 제공

## 7. 차별점 및 경쟁 분석

### 7.1 경쟁사 분석

| 경쟁사 게임 | 장점 | 약점 | 우리의 차별화 |
|-------------|------|------|----------|
| **Sort Puzzle** | 인기, 많은 사용자 | 높은 과금, 과도한 광고 | 깔끔한 UI, 최소 광고 |
| **Water Sort** | 비슷한 메커니즘 | 병 게임 (덜 직관적) | 공 게임 (더 직관적) |
| **Color Sort** | 색깔 중심 게임 | 깊이 부족 | 깊이 있는 전략 |
| **Ball Blast** | 액션 요소 | 퍼즐 요소 부족 | 순수 퍼즐 집중 |

### 7.2 우리의 차별점

#### 1. **직관적 조작성**
- 공은 색상별 분류 개념이 직관적
- 터치 기반 조작이 자연스러움
- 시각적으로 목표가 명확함

#### 2. **깊이 있는 전략성**
- 단순 규칙 (맨 위만 이동) 속의 깊은 전략성
- 이동 순서가 중요한 조합 최적화
- 각 게임마다 다른 해결 방법 존재

#### 3. **현대적 UI/UX**
- 깔끔한 플랫 디자인
- 부드러운 애니메이션
- 반응형 레이아웃 (모바일/데스크톱)

#### 4. **공정한 과금 정책**
- 무료로 모든 난이도 클리어 가능
- 광고는 선택적 (보상형만)
- 과금은 편의성만 제공 (게임 진행 가속 없음)

#### 5. **점진적 난이도 곡선**
- Easy부터 Expert까지 매끄러운 난이도 증가
- 각 난이도가 새로운 도전 제공
- 초보자부터 마스터까지 모두 즐길 수 있음

### 7.3 시장 포지셔닝

**타겟 마켓**: 
- 메인: 10-40세 캐주얼 게이머
- 서브: 40세 이상 퍼즐 게임 팬

**포지셔닝 메시지**:
"간단한 규칙, 무한한 도전. Ball Sort Puzzle에서 당신의 논리를 시험하세요."

**유통 전략**:
1. 웹 버전: itch.io, 개인 웹사이트
2. 모바일: iOS App Store, Google Play (추후)
3. 데스크톱: Steam (추후)

## 8. 향후 확장 계획

### 8.1 콘텐츠 확장
- **신규 난이도**: Nightmare (12+색) 레벨 추가
- **특수 레벨**: 제약 조건 있는 특별 레벨
  - 튜브 용량 감소 (3개 → 2개)
  - 움직일 수 없는 공 (잠금)
  - 색상 추가 (혼합색)

### 8.2 게임 모드 확장
- **일일 챌린지**: 매일 같은 난이도의 신규 게임
- **토너먼트 모드**: 7일 연속 게임 점수 합산
- **무한 모드**: 난이도 점진적 상승으로 무한 진행
- **타임 어택**: 시간 제한 내에 클리어하는 모드

### 8.3 소셜 기능 (선택적)
- **온라인 리더보드**: 전 세계 플레이어와 점수 비교
- **친구 초대**: 친구와 점수 경쟁
- **점수 공유**: SNS에 점수 기록 공유

### 8.4 접근성 개선
- **색맹 모드**: 색맹 친화적 팔레트
- **고대비 모드**: 시각 장애자를 위한 고대비
- **음성 안내**: 음성 피드백
- **큰 UI**: 고령자를 위한 큰 버튼/텍스트
