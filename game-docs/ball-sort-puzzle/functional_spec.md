# Ball Sort Puzzle - Functional Specification

## 1. 게임 개요

**게임명**: Ball Sort Puzzle
**형식**: 단일 HTML5 파일
**장르**: 색깔 공 정렬 퍼즐
**핵심 목표**: 모든 공을 같은 색으로 튜브에 정렬하기

## 2. 기술 스택

| 항목 | 상세 |
|------|------|
| 플랫폼 | HTML5 (단일 파일) |
| 개발 언어 | JavaScript (Vanilla) + CSS3 |
| 렌더링 | Canvas API 또는 DOM (SVG/DIV) |
| 애니메이션 | CSS3 Animations + JavaScript Tweens |
| 저장소 | localStorage (게임 진행 상태) |
| 배포 | 웹 서버 또는 로컬 파일 |

## 3. 핵심 게임 시스템

### 3.1 튜브 및 공 시스템

#### 튜브 구성
- **튜브 용량**: 고정 용량 (TUBE_CAPACITY = 4개 기준)
- **초기 튜브 수**: 플레이어 영웅 수에 따라 결정
  - 예: 12색 공이 있으면 3개 튜브 (각 4개씩)
  - 공의 총 개수 = 색상 수 × TUBE_CAPACITY
- **추가 빈 튜브**: 플레이를 위해 2개의 추가 빈 튜브 제공
- **총 튜브 수**: 색상 수 / 4 + 2 (예: 3 + 2 = 5개)

#### 공의 속성
- **색상**: RGB 값으로 구분 (라디알 그라디언트로 표현)
- **위치**: 튜브 내부, 스택 구조 (LIFO - Last In First Out)
- **상태**: 이동 가능/불가능

### 3.2 이동 규칙

#### 이동 가능 조건
1. **맨 위의 공만 이동 가능**
   - 튜브의 맨 위에 있는 공만 선택 및 이동 가능
   - 아래 공들은 이동 불가능

2. **목표 튜브 조건**
   - **같은 색 위로만 이동 가능**: 목표 튜브의 맨 위 공이 같은 색이거나
   - **빈 튜브로만 이동 가능**: 목표 튜브가 완전히 비어있어야 함

3. **용량 제한**: 튜브 용량을 초과하여 이동 불가능

#### 이동 불가능한 경우
- 튜브가 가득 찼을 때 (TUBE_CAPACITY 도달)
- 목표 튜브의 색상이 다를 때
- 맨 아래의 공을 선택하려고 할 때

### 3.3 게임 진행 시스템

#### 게임 시작
- **초기 배치**: 공들을 튜브에 무작위로 배치
  - 각 색상별로 TUBE_CAPACITY개 배치
  - 같은 색끼리 모여있지 않도록 섞임
- **빈 튜브 2개 준비**: 초기 상태에서 공간 마련

#### 게임 진행
1. 플레이어가 공 선택 (자동으로 맨 위 공 선택)
2. 목표 튜브 선택
3. 이동 규칙 검증
4. 이동 실행 (애니메이션)
5. 완성된 튜브 확인 (같은 색 4개)
6. 게임 종료 조건 확인

#### 게임 종료 조건

- **승리 (Win)**: 모든 공이 색상별로 분류되어 각 튜브가 완성됨
  - 모든 튜브가 같은 색 공 4개씩으로 구성
  - 축하 연출 및 점수 표시

- **패배 (Lose)**: 가능한 이동이 없음 (Stalemate)
  - 모든 선택 가능한 공이 어디로도 이동 불가능
  - "불가능한 상황" 표시

### 3.4 게임 도구 시스템

#### 힌트 (Hints)
- **제한**: 게임당 3회 제공
- **기능**:
  1. 완성된 튜브 강조 (같은 색 4개가 모여있는 튜브 표시)
  2. 다음 가능한 이동 제안 (출발 튜브 → 목표 튜브 하이라이트)
  3. 같은 색 이동 우선 제안
- **카운트 표시**: "Hints: 2/3"

#### 셔플 (Shuffle)
- **제한**: 게임당 1회 제공
- **기능**: 현재 배치된 공들을 무작위로 재배치
  - 완성된 튜브는 변경하지 않음 (선택사항)
  - 새로운 해결 경로 제공
- **제약**: 게임 진행률 70% 이상일 때는 사용 불가 (선택사항)

#### 되돌리기 (Undo)
- **기능**: 마지막 이동 취소
- **제한**: 게임당 최대 5회
- **활용**: 실수한 이동 즉시 복구

### 3.5 점수 시스템

#### 점수 산정
- **기본 점수**: 공 1개 이동 = 1점
- **보너스 점수**:
  - 튜브 완성: +50점 (같은 색 4개 완성)
  - 연속 완성 (콤보): 2개 이상 튜브 연속 완성 = +100점
  - 신속 클리어 (이동 횟수 적음): 최소 이동 횟수 = +200점
- **페널티**: 힌트 사용 시 -5점

#### 최고 점수 기록
- **로컬 저장**: localStorage에 저장
- **베스트 기록**: 플레이 레벨별 최고 점수

## 5. UI/UX 명세

### 5.1 주요 화면

| 화면명 | 기능 |
|--------|------|
| **메인 메뉴** | 게임 시작, 진행 중인 게임 계속하기, 설정 |
| **게임 화면** | 튜브 표시, 도구 버튼, 점수 표시, 이동 횟수 |
| **게임 결과** | 승리/패배 결과, 최종 점수, 베스트 스코어, 재시작 |

### 5.2 게임 화면 UI 요소

- **튜브 표시 영역**
  - 튜브 5개 배치 (3개 컬러 튜브 + 2개 빈 튜브)
  - 각 튜브: 원형 또는 사각형 컨테이너, 내부 공 시각화
  - 선택된 튜브 강조 (테두리 밝아짐)
  - 공 개수 표시 (숫자 또는 시각적)

- **도구 버튼 바** (하단)
  - "힌트" 버튼 (남은 횟수: 3/3)
  - "셔플" 버튼 (제공 여부: [O] 또는 [X])
  - "되돌리기" 버튼 (남은 횟수: 5/5)
  - "메뉴로" 버튼

- **정보 표시 영역** (상단)
  - 현재 점수: 350점
  - 이동 횟수: 24
  - 완성된 튜브: 2/5

### 5.3 공 디자인

#### 공의 외형
- **크기**: 지름 40px (또는 반응형)
- **형태**: 원형 (circle)
- **색상**: 라디알 그라디언트 (입체감 표현)
  - 밝은 색 (하이라이트) → 어두운 색 (쉐이도우)
- **효과**: 미묘한 그림자 (shadow)

#### 공의 상태
- **기본 상태**: 색상 그대로
- **선택 상태**: 테두리 (3px, 흰색)
- **이동 가능 상태**: 약간 밝아짐 (투명도 변경)
- **이동 불가능 상태**: 어둡게 표시 (투명도 감소)

- 청록: #33FFFF

- 검정: #333333

## 7. 게임 난이도

### 7.1 난이도 단계

| 난이도 | 색상 수 | 튜브 수 | 특징 |
|--------|---------|--------|------|
| **Easy** | 2-3색 | 4-5개 | 짧은 해결 시간, 몇 가지 이동만으로 완성 |
| **Normal** | 4-5색 | 6-7개 | 중간 난이도, 전략적 사고 필요 |
| **Hard** | 6-7색 | 8-9개 | 높은 난이도, 최적 경로 찾기 어려움 |
| **Expert** | 8-12색 | 10-14개 | 매우 어려움, 숙련자용 |

### 7.2 난이도 조절

- **점진적 증가**: Easy → Normal → Hard → Expert 순서로 진행 권장
- **레벨별 도구**: 어려울수록 더 많은 도구 제공
- **자유 선택**: 원하는 난이도를 언제든 선택 가능
- **랜덤 생성**: 같은 난이도 내에서 매번 다른 배치
