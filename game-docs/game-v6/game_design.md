## game-v6 게임 설계 문서

### 프로젝트 컨셉
game-v6는 다양한 장르의 게임을 자동으로 생성하는 Python 게임 생성기입니다. 각 게임은 HTML5 Canvas와 Vanilla JavaScript로 구현되며, 플레이어 편의성을 위한 FPS 모니터링, 멀티터치 지원, 클라우드 세이브 기능을 표준으로 제공합니다.

### 메카닉 분류
**Game Generator / Multi-genre (Puzzle, Strategy, Arcade)**

### 프로젝트 비전
모든 게임에 일관된 사용자 경험을 제공하면서도 장르별 고유한 게임플레이를 구현할 수 있는 확장 가능한 생성 시스템 구축

### 생성 게임 포트폴리오

#### 1. Echo Navigator (퍼즐)
- **컨셉**: 에콜로케이션 펄스를 이용한 미로 네비게이션
- **핵심 메카닉**: 음파 반사 기반 위치 감지, 장애물 회피
- **타겟**: 사고력 게이머, 보조 기술 사용자

#### 2. Mirror Maze (퍼즐)
- **컨셉**: 거울 반사를 이용한 레이저 경로 설계
- **핵심 메카닉**: 거울 배치, 각도 조정, 레이저 반사
- **타겟**: 공간 지각력 게이머

#### 3. Root Network (전략)
- **컨셉**: 뿌리 네트워크 확장 및 자원 관리
- **핵심 메카닉**: 타일 기반 배치, 자원 흐름 최적화
- **타겟**: 시뮬레이션 게이머

#### 4. Kite Messenger (아케이드)
- **컨셉**: 연줄 장력을 조종하여 메시지 전달
- **핵심 메카닉**: 실시간 장력 조절, 풍속 변수
- **타겟**: 반사 신경 게이머

#### 5. Thermal Drift (아케이드)
- **컨셉**: 열 기류를 이용한 비행 조종
- **핵심 메카닉**: 물리 기반 부양, 열 감지
- **타겟**: 조종 게이머

#### 6-10. 추가 5개 게임
- 다양한 장르 및 난이도로 포트폴리오 확대

### 핵심 재미 요소

#### 1. 일관된 품질 경험
모든 게임이 표준화된 UI/UX를 통해 동일한 수준의 완성도 제공

#### 2. 빠른 접근성
세이브/로드로 언제 어디서나 중단한 지점부터 계속 플레이

#### 3. 다양한 장르 경험
한 플랫폼에서 여러 게임 장르를 순회하며 즐길 수 있음

#### 4. 성능 피드백
FPS 모니터를 통해 사용자가 게임 성능을 이해하고 최적화 판단

### 게임플레이 루프

```
시작 → 메뉴 (신규/계속) → 게임 플레이
                          ├─ 입력 처리 (키보드/터치)
                          ├─ 게임 로직 업데이트
                          ├─ Canvas 렌더링 (FPS 표시)
                          ├─ 자동 저장
                          └─ 클리어/실패 시 메뉴로 복귀
```
