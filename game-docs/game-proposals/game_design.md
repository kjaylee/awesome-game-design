## game-proposals 게임 설계 문서

### 프로젝트 컨셉
20개의 완전한 게임 기획 제안서 모음입니다. 각 게임은 독립적으로 개발 가능하며, 공통 기술 기반과 수익화 전략을 공유합니다. 캐주얼부터 중간 코어 게이머까지 아우르는 다양한 장르를 제시합니다.

### 메카닉 분류
**Multi-genre Proposal Collection**

### 프로젝트 비전
HTML5 기반 캐주얼 게임 생태계를 구축하되, 개별 게임의 차별화된 메카닉과 높은 완성도를 통해 다양한 플레이어 세그먼트를 공략하고, 지속 가능한 수익화 모델을 구현하는 것

### 핵심 재미 요소 (공통)

#### 1. 즉시적 만족감
- 명확한 피드백 (점수, 음향, 비주얼)
- 짧은 세션 (5-15분)
- 빠른 클리어 감각

#### 2. 점진적 난이도 곡선
- 초반 쉬운 난이도로 습득
- 중반 도전적 요소 증가
- 후반 마스터 플레이 보상

#### 3. 다양한 진행 기준
- 점수 경쟁
- 퍼즐 해결
- 콜렉션 완성
- 성취 언락

#### 4. 사회적 연결
- 리더보드 경쟁
- 친구 초대
- 성취 공유

### 수익화 전략 (표준)

#### 광고 배치
- **배너**: 메뉴 화면 하단 (항상 표시)
- **전면**: 게임 오버 후 (선택형)
- **보상형**: 힌트/보너스 획득 시 (명시적)
- **예상 수익**: 배너 $0.5-1.0 CPM, 보상형 $2-4 eCPM

#### 인앱 구매
- **광고 제거**: $4.99/월 (가장 높은 CVR)
- **힌트**: $0.99-$4.99 (게임별 다양화)
- **부스트**: $0.99-$9.99 (시간/점수 배수)
- **예상 수익**: ARPU $0.75-$2.0/월

#### 수익화 혼합
- 광고 60-70% (초기/미인증 사용자)
- IAP 30-40% (충동구매 + 구독)
