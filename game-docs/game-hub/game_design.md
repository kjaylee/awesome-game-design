## game-hub 게임 설계 문서

### 프로젝트 컨셉
game-hub는 게임 개발 생태계의 중앙 허브 역할을 합니다. 수백 개의 게임을 효율적으로 관리하고, 사용자가 쉽게 게임을 발견하고 접근할 수 있는 플랫폼을 제공합니다.

### 메카닉 분류
**Platform / Game Management Hub**

### 프로젝트 비전
분산된 게임 자산과 메타데이터를 중앙에서 관리하여 일관성 있고 확장 가능한 게임 생태계를 구축하되, 개별 게임의 완전한 독립성을 보장하는 것

### 핵심 가치

#### 1. 게임 발견 용이성
- 명확한 분류와 검색
- 개인화된 추천
- 신규 게임 자동 하이라이트

#### 2. 운영 효율성
- 통합 배포 시스템
- 자동 버전 관리
- 배포 상태 실시간 모니터링

#### 3. 품질 보증
- 통일된 기술 표준
- 필수 QA 체크리스트
- 성능 벤치마킹

#### 4. 사용자 신뢰
- 투명한 게임 정보
- 커뮤니티 평점/리뷰
- 명확한 지원 채널

### 게임플레이 루프 (플랫폼 관점)

```
사용자 방문
  ↓
게임 발견 (검색/추천)
  ├─ 장르 브라우징
  ├─ 평점 필터링
  └─ 신규 게임 하이라이트
  ↓
게임 상세 페이지
  ├─ 스크린샷/영상
  ├─ 커뮤니티 리뷰
  ├─ 요구사항 확인
  └─ 설치 버튼
  ↓
게임 설치/플레이
  ↓
[피드백/리뷰 작성]
  ↓
[다음 게임 발견]
```

### 운영 워크플로우

#### 일일 운영
```
09:00 - 배포 상태 확인
10:00 - 신규 게임 QA 검증
11:00 - 카탈로그 동기화
14:00 - 성능 모니터링
16:00 - 사용자 피드백 검토
```

#### 주간 운영
```
월요일 - 주간 게임 출시 계획
화요일 - 신규 게임 추가 (1-2개)
수요일 - 성능 분석 및 최적화
목요일 - 커뮤니티 피드백 분석
금요일 - 마케팅 공지 및 보도자료
```

#### 월간 운영
```
1주차 - 월간 목표 설정
2주차 - 카탈로그 대규모 동기화
3주차 - 성능 리뷰 및 아카이빙 결정
4주차 - 다음 분기 계획
```

### 카탈로그 구조

#### 게임 분류 (주요 장르)
- **Puzzle** (150개): 논리, 매치-3, 블록 배치 등
- **Arcade** (80개): 슈팅, 플랫포머, 액션 등
- **Strategy** (40개): 턴제, RTS, 타워 디펜스 등
- **Idle** (30개): AFK 게이머 대상
- **Simulation** (20개): 관리, 경영 시뮬레이션
- **Rhythm** (15개): 음악/비트 매칭
- **Casual** (23개): 기타 캐주얼 게임

#### 게임 메카닉 분류
- **Generator**: gen_v6, gen_v9, gen_v10
- **AI-enhanced**: AI 동반자/NPC 시스템 포함
- **Accessible**: 완전 접근성 기능 포함
- **Physics-based**: 물리 엔진 활용
- **Story-driven**: 이야기 중심
