## Derby Dash 확장 기획 (Phase 6~7) - 게임 디자인 문서

## 게임 컨셉 및 비전

Derby Dash는 간단한 경마 게임에서 **포괄적인 경마 시뮬레이션 플랫폼**으로 진화합니다. Phase 6~7을 통해 콘텐츠 다양성, 게임 깊이, 플레이어 참여도를 크게 확대합니다.

## 메카닉 분류

**Racing / Content Generation**

기본 경마 게임에 새로운 콘텐츠 (말, 트랙, 통계), 게임플레이 메카닉 (특수 능력, 환경 변수), 분석 시스템 (통계, 조언)을 추가하는 확장 프로젝트입니다.

## 핵심 재미 요소

### Phase 6: 말 추가의 재미

#### 1. 고유 메커니즘의 발견
- Phantom Runner의 후반 가속이라는 새로운 패턴 체험
- 각 말의 성격을 체험하며 선호도 형성

#### 2. 전략성 증대
- 10마리 말 중 최적 선택 고민
- 약자의 역전 가능성으로 새로운 배팅 기회

#### 3. 수집 심리
- 모든 말의 승리 달성 (콜렉션)
- 말별 개인 기록 추적 및 개선

### Phase 7: 트랙 및 통계의 재미

#### 1. 환경 변화에 따른 신선함
- 같은 말도 트랙에 따라 다른 성능
- 전략적 선택지 증대 (말 + 트랙 조합)

#### 2. 데이터 기반 게임플레이
- 과거 통계로 결정 내리는 만족감
- 수익률 추적으로 진행 상황 가시화

#### 3. 게임 깊이의 확장
- 초보자: 직관적 베팅
- 중급자: 트렌드 분석 활용
- 고급자: 배당률 계산 및 팁 활용

## 게임플레이 루프 (확장)

### Phase 6 업그레이드된 루프

```
[말 선택]
  ├─ 기본 9마리 말
  └─ 신규 Phantom Runner (고유 능력)
    ↓
[베팅]
  ├─ 말별 배당률
  └─ 과거 성적 참고
    ↓
[경주 진행]
  ├─ 실시간 속도 변화
  └─ Phantom Runner 특수 애니메이션
    ↓
[결과 기록]
  └─ 말별 히스토리 누적
```

### Phase 7 고급 루프

```
[트랙 선택] ← NEW
  ├─ Classic, Mountain, Desert, Forest, Night, Storm
  └─ 각 트랙별 특성 이해
    ↓
[분석 및 팁] ← NEW
  ├─ 최근 형태 분석
  ├─ 트랙별 강점 분석
  └─ 배팅 조언 제시
    ↓
[전략적 베팅]
  ├─ 팁 기반 선택
  ├─ 배당률 계산
  └─ 금액 결정
    ↓
[경주 진행]
    ↓
[통계 확인]
  ├─ 개인 기록
  ├─ 말별 통계
  └─ 트랙별 성능
```

## 밸런싱 전략

### Phantom Runner 밸런싱

**문제점**: 후반 가속 능력이 너무 강하면 게임 붕괴

**해결책**:
- 초반 성능을 낮게 설정 (약 5/10)
- 후반 부스트를 중반부터 점진적 상승
- 배당률을 높게 설정 (8~15%) 으로 수익성 조정

**테스트 목표**: 
- 승률: 약 10% (다른 말과 비슷)
- 시간당 이익: 평균과 동일

### 트랙 특성 밸런싱

**목표**: 각 트랙에서 다른 말이 우승할 수 있도록

**예시**:
- Classic: 모든 말 동등 (50% 표준편차)
- Mountain: 지구력 높은 말 유리 (30% 표준편차)
- Desert: 인내력 말 유리 (35% 표준편차)
- Forest: 빠른 말 유리 (35% 표준편차)
- Night: Midnight Swift 특별 보너스 (+15%)
- Storm: Silver Storm 특별 보너스 (+15%)
