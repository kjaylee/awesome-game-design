## games 게임 설계 문서

### 프로젝트 컨셉
games 폴더는 EastSea 게임 생태계의 중추적 역할을 하며, 600개 이상의 다양한 게임을 호스팅하고 관리하는 메인 플랫폼입니다. 자동 테스트, 국제화, CI/CD 파이프라인을 통해 높은 품질과 일관성을 유지합니다.

### 메카닉 분류
**Platform / Game Catalog (Multi-genre, 600+)**

### 프로젝트 비전
600개 이상의 게임을 호스팅하면서도 각 게임의 독립성을 보장하고, 자동화된 품질 관리 체계를 통해 사용자에게 신뢰할 수 있는 게임 플랫폼을 제공하는 것

### 핵심 가치

#### 1. 게임 다양성
- 모든 장르를 포괄하는 600개 게임
- 캐주얼부터 하드코어까지 다양한 난이도
- 신규 개발자의 실험 게임 환영

#### 2. 자동 품질 관리
- 배포 전 자동 검증
- 성능 모니터링
- 에러 추적 및 빠른 수정

#### 3. 글로벌 접근성
- 6개 언어 지원
- 국제화 파이프라인
- 지역별 통화/시간대 지원

#### 4. 개발자 친화적
- 간단한 배포 프로세스
- 수익 분배 투명성
- 기술 지원 및 컨설팅

### 게임 발견 경험

#### 사용자 여정
```
games.eastsea.xyz 방문
  ↓
게임 발견
├─ 신규 게임 하이라이트 (최근 1주)
├─ 인기 게임 순위 (다운로드/평점)
├─ 장르별 브라우징
├─ 검색 (게임명/메카닉)
└─ 개인화 추천 (플레이 이력 기반)
  ↓
게임 상세 페이지
├─ 스크린샷 5장
├─ 게임플레이 영상 (30초)
├─ 사용자 리뷰 및 평점
├─ 기술 사양 (용량, 대응 OS)
└─ 설치/웹 플레이 버튼
  ↓
게임 시작
  ├─ 웹 플레이 (즉시)
  └─ 모바일 앱 (설치 후)
  ↓
플레이 및 평가
  ├─ 게임 중 팝업: "평가하기"
  └─ 플레이 종료 후 리뷰 작성 유도
```
