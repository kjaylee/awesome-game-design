# Retro Ricochet — 레트로 리코셈 — 아케이드 게임 기획서

> **슬러그**: `retro-ricochet` | **장르**: 아케이드 | **플랫폼**: Web (HTML5) | **엔진**: Static Web
>
> **태그**: `rhythm, runner`

## 1. 게임 개요

### 1.1 핵심 컨셉

Retro Ricochet는 브라우저에서 즉시 실행 가능한 **아케이드** 장르의 HTML5 게임입니다.
플레이어는 직관적인 인터랙션을 통해 BPM 동기 탭 입력, 정확도 판정(Perfect/Good/Miss); 자동 전진, 장애물 회피, 리듬감 있는 반사 조작을 경험하며,
빠른 세션과 높은 재플레이성을 핵심 가치로 합니다.

### 1.2 장르 & 플랫폼

| 항목 | 내용 |
|------|------|
| 장르 | 아케이드 |
| 플랫폼 | 웹 브라우저 (PC/Mobile) |
| 엔진 | HTML5 Canvas / Static Web |
| 해상도 | 360×640 (모바일 기준), PC 자동 스케일 |
| 입력 | 터치/마우스 클릭, 키보드 방향키/스페이스바 |

### 1.3 타겟 플레이어

- **Primary**: 25~35세, 짧은 여가 시간에 캐주얼 게임을 즐기는 직장인
- **Secondary**: 15~24세, 인디 게임/장르 순수주의자
- **페르소나**: "5분 짜리 게임이지만 하나 더 하게 되는" 반복성 추구형

### 1.4 차별점

1. **즉시 실행** — 설치 없이 URL 접근만으로 전체 게임 경험 제공
2. **최적화된 루프** — 첫 10초 이내 코어 메카닉 체험 가능한 온보딩
3. **아케이드 특화 메카닉** — rhythm, runner 조합으로 장르 내 독자적 포지셔닝

### 1.5 레퍼런스 게임

  - **Asteroids** — 관성 기반 이동
  - **Geometry Wars** — 트윈스틱 슈터
  - **Pac-Man** — 경로 최적화

## 2. 핵심 게임 루프

### 2.1 코어 루프 다이어그램

```
게임 시작 → 장애물 회피/적 격파 → 점수 획득 → 난이도 상승 → 게임오버 → 재시작
  - 코어: 반사 신경 + 패턴 학습
  - 루프 길이: 1~3분
```

### 2.2 메타 루프 (세션 간 진행)

```
첫 플레이
  ↓
코어 루프 반복 (점수/레벨 축적)
  ↓
해금 조건 달성 (스코어 임계값 / 레벨 완료)
  ↓
신규 콘텐츠 언락 (스킨 / 모드 / 레벨)
  ↓
심화 목표 제시 → 코어 루프 재진입
```

### 2.3 게임 오버 조건 & 리워드

| 조건 | 트리거 | 보상 |
|------|--------|------|
| 일반 종료 | 목표 달성 / 시간 소진 | 점수 + 별점 평가 |
| 게임오버 | 실패 조건 (HP 소진 등) | 재시작 버튼 + 광고 부활 |
| 최고점 갱신 | 이전 기록 초과 | 애니메이션 축하 + 공유 유도 |

## 3. 게임 시스템

### 3.1 핵심 메카닉

**rhythm, runner** 메카닉을 중심으로 설계:

- **rhythm**: BPM 동기 탭 입력, 정확도 판정(Perfect/Good/Miss)
- **runner**: 자동 전진, 장애물 회피, 리듬감 있는 반사 조작

조작 방식:
- 터치: 탭, 스와이프, 드래그
- 키보드: 방향키, 스페이스바, 숫자키(1~3)
- 반응 시간 기준: 150ms 이내 인풋 처리

### 3.2 보조 메카닉

- **연속 성공 보너스(콤보)**: 연속 N회 성공 시 점수 배율 1.5→2.0→3.0×
- **파워업**: 3종 (속도 증가 / 무적 / 배율 2배), 5~10초 지속
- **이벤트 트리거**: 특정 점수 임계값 도달 시 희귀 이벤트 발생

### 3.3 경제 시스템

```
수입 흐름:
  플레이 → 점수 → 코인 환산 (100점 = 1코인)
  광고 시청 → 코인 2배
  일일 미션 완료 → 보너스 코인

지출 흐름:
  스킨 구매 (100~500 코인)
  컨티뉴 사용 (50 코인)
  힌트 구매 (30 코인)
```

### 3.4 진행 시스템

| 단계 | 언락 조건 | 보상 |
|------|-----------|------|
| 1단계 | 기본 시작 | 기본 스킨 + 1스테이지 |
| 2단계 | 스코어 1000+ | 스킨 2종 + 2스테이지 |
| 3단계 | 스코어 5000+ | 특수 모드 해금 |
| 4단계 | 스코어 10000+ | 최종 스킨 + 엔딩 크레딧 |

## 4. 콘텐츠 설계

### 4.1 맵/레벨 구성

- **기본 모드**: 20~30개 큐레이션 레벨 (튜토리얼 3 + 일반 17 + 챌린지 10)
- **무한 모드**: 절차적 생성 레벨, 난이도 점진 상승
- **일일 챌린지**: 매일 교체되는 특수 레벨 1개

난이도 곡선:
```
레벨 1~5:   ★☆☆☆☆  (온보딩, 튜토리얼)
레벨 6~12:  ★★☆☆☆  (기본 메카닉 학습)
레벨 13~20: ★★★☆☆  (복합 패턴)
레벨 21~28: ★★★★☆  (심화 도전)
레벨 29~30: ★★★★★  (극한 챌린지)
```

### 4.2 적/장애물 설계

| 유형 | 속성 | 등장 레벨 |
|------|------|-----------|
| 기본 | 단순 이동, 저속 | 1+ |
| 고속 | 빠른 이동, 예측 어려움 | 5+ |
| 보스형 | 복합 패턴, 다단 격파 | 10+ |
| 특수 | 분열/복제/역방향 | 15+ |

### 4.3 아이템/스킬 목록

| 아이템 | 효과 | 획득 방법 |
|--------|------|-----------|
| 🛡️ 실드 | 1회 피해 무효 | 레벨 클리어 |
| ⚡ 부스트 | 속도/파워 2배 (5초) | 콤보 10+ |
| 💫 자석 | 주변 아이템 자동 획득 | 광고 시청 |
| ❄️ 프리즈 | 적/장애물 2초 정지 | IAP |

### 4.4 스토리 & 세계관

**Retro Ricochet**의 배경:
> 미래 도시의 디지털 공간 안, 플레이어는 아케이드 챔피언 타이틀을 위해 경쟁합니다.
> 각 레벨은 도시의 서로 다른 구역을 표현하며, 점점 높아지는 난이도는
> 더 깊은 디지털 레이어로의 침투를 상징합니다.

세계관 키워드: 네온, 디지털, 미래, 도전, 성장

## 5. UX/UI 설계

### 5.1 화면 흐름 (Screen Flow)

```
스플래시 화면 (1.5초)
    ↓
메인 메뉴
  ├── 플레이 시작
  ├── 레벨 선택
  ├── 상점
  ├── 설정
  └── 크레딧
    ↓
게임플레이 화면
  ├── HUD (점수/시간/HP)
  ├── 일시정지 → 재개/재시작/메뉴
  └── 게임오버 → 결과 → 재시작/메뉴
```

### 5.2 HUD 구성

```
┌─────────────────────────────────┐
│ [←뒤로]  SCORE: 0000  [⚙설정]  │ ← 상단 바
├─────────────────────────────────┤
│                                 │
│           게임 화면              │
│           (캔버스)               │
│                                 │
├─────────────────────────────────┤
│ [💫파워업1] [⚡파워업2] [❄파워업3]│ ← 하단 액션 바
└─────────────────────────────────┘
```

### 5.3 메뉴 구조

- 메인메뉴: 플레이/레벨선택/상점/랭킹/설정
- 인게임: 일시정지/재시작/홈
- 결과화면: 점수/별점/공유/다음레벨/재도전

### 5.4 접근성 고려사항

- 색맹 모드 지원 (색상 + 형태 이중 코딩)
- 텍스트 크기 조절 (Small/Medium/Large)
- 진동 피드백 옵션 (모바일)
- 배경음 없이도 게임 가능한 시각 피드백

## 6. 아트 디렉션

### 6.1 비주얼 컨셉 & 레퍼런스

**컨셉 키워드**: 아케이드 + 네온 사이버펑크 + 미니멀 UI

비주얼 레퍼런스:

### 6.2 색상 팔레트

| 역할 | 색상 | 헥스코드 |
|------|------|----------|
| Background | 메인 배경 | `#060612` |
| Primary | 주요 액션 | `#ff2244` |
| Surface | 카드/패널 | `#0a0a1a` |
| Accent | 강조/하이라이트 | `#ffbb00` |
| Success | 성공 피드백 | `#00ff88` |
| Danger | 위험/실패 | `#ff4444` |
| Text | 본문 텍스트 | `#e2e8f0` |
| Muted | 보조 텍스트 | `#64748b` |

### 6.3 타이포그래피 스택

| 용도 | 폰트 | 사이즈 |
|------|------|--------|
| 게임 타이틀 | Press Start 2P | 32~48px |
| 점수/수치 | VT323 | 24~32px |
| HUD 레이블 | Inter | 12~14px |
| 본문/설명 | Inter | 14~16px |
| 캡션/힌트 | Inter Light | 11~12px |

### 6.4 애니메이션 가이드라인

- **입력 피드백**: 탭/클릭 시 0.15초 scale 1.0→1.1→1.0 스프링
- **성공 이펙트**: 파티클 폭발 + 화면 플래시 (0.3초)
- **게임오버**: 화면 흔들림(shake) 0.5초 + 페이드 아웃
- **레벨업/언락**: 골드 파티클 상승 + 텍스트 팝업 (1초)
- **콤보 카운터**: 숫자 카운트업 + 크기 증가 애니메이션
- **이징**: 모든 UI 전환은 `ease-out cubic` 150~300ms

## 7. 수익화 전략

### 7.1 비즈니스 모델

**광고 기반 + 부활권 IAP + 프리미엄 스킨**

### 7.2 수익화 포인트

| 포인트 | 방식 | 예상 전환율 |
|--------|------|------------|
| 게임오버 부활 | 광고 30초 시청 | 35% |
| 광고 제거 | 일회성 IAP ₩1,100 | 5% |
| 스킨팩 | 3종 세트 ₩2,200 | 3% |
| 힌트팩 | 10개 ₩1,100 | 8% |

### 7.3 밸류 프로포지션

- **무료 플레이어**: 광고 시청으로 전체 콘텐츠 이용 가능
- **라이트 과금**: ₩1,100 광고 제거로 순수 게임 경험
- **헤비 유저**: 스킨/효과 수집을 통한 자기표현

### 7.4 윤리적 고려사항

- Pay-to-Win 요소 없음 — 모든 수익화는 코스메틱 또는 편의성
- 미성년자 과금 방지 — 구매 전 확인 팝업 필수
- FOMO 최소화 — 시간 제한 콘텐츠에 게임플레이 보상 배제
