# Mahjong Zen - Functional Specification

## 1. 게임 개요

**게임명**: Mahjong Zen
**형식**: 단일 HTML5 파일
**장르**: 마작 솔리테어 퍼즐
**목표**: 마작 타일을 모두 제거하여 게임 승리

## 2. 기술 스택

| 항목 | 상세 |
|------|------|
| 플랫폼 | HTML5 (단일 파일) |
| 개발 언어 | JavaScript (Vanilla) |
| 렌더링 | Canvas API 또는 DOM 기반 |
| 저장소 | localStorage (게임 진행 상태 저장) |
| 배포 | 웹 서버 또는 로컬 파일 실행 |

## 3. 핵심 게임 시스템

### 3.1 마작 타일 시스템

#### 타일 구성
- **타일 종류**: 136개 표준 마작 타일
- **타일 분류**:
  - **숫자 타일 (Numbers)**: 1~9 × 4세트 (36개)
  - **바람 타일 (Winds)**: 동(E), 남(S), 서(W), 북(N) × 4개 (16개)
  - **용 타일 (Dragons)**: 백(White), 초(Green), 중(Red) × 4개 (12개)
  - **꽃 타일 (Flowers)**: 4종류 (4개)
  - **계절 타일 (Seasons)**: 4종류 (4개)
  - **보너스**: 추가 특수 타일 (추후)

#### 타일 매칭 규칙
- **기본 규칙**: 같은 타입의 타일 2개를 "눈(Eye)"으로 선택 가능
- **메즈 선택**: 연속된 3개의 같은 타입 타일을 "메즈(Meld)"로 제거 가능
  - 예: 숫자 1, 2, 3 (순서대로) → 제거
- **보너스 조합**: 특수 조합 시 추가 점수 부여
- **매칭 검증**: 선택한 2개 타일이 "노출" 상태여야 함 (다른 타일에 가려져 있지 않음)

### 3.2 게임 진행 시스템

#### 게임 시작
- **초기 배치**: 136개 타일을 특정 패턴으로 배치 (금자탑, 동쪽, 북쪽 등)
- **초기 상태**: 모든 타일 노출 (겹쳐있지 않음)

#### 게임 진행
1. 플레이어가 제거 가능한 타일 2개를 선택
2. 규칙 검증 (같은 타입, 노출 상태)
3. 타일 제거 (애니메이션)
4. 점수 추가
5. 배치 업데이트 (새로운 타일 노출)
6. 게임 종료 조건 체크 (모든 타일 제거 또는 가능한 이동 없음)

#### 게임 종료 조건

- **승리 (Win)**: 모든 타일 제거
  - 점수 표시
  - 축하 연출 애니메이션
  - 재시작 옵션 제공

- **패배 (Lose)**: 가능한 이동이 없음 (Stalemate)
  - 남은 타일 수 표시
  - 패배 메시지
  - 재시작 또는 힌트 옵션

### 3.3 게임 도구 시스템

#### 힌트 (Hints)
- **제한**: 게임당 3회 제공
- **기능**: 플레이어가 "힌트" 버튼 클릭 시
  1. 제거 가능한 타일 쌍을 강조 표시
  2. 제거 가능한 타일이 없으면 "No Moves Available" 메시지
- **카운트 표시**: 남은 힌트 수 UI에 표시 (예: "Hints: 2/3")

#### 셔플 (Shuffle)
- **제한**: 게임당 1회 제공
- **기능**: 현재 배치된 타일의 위치를 무작위로 재배치
  - 게임 규칙 유지 (노출/은폐 상태 변경 없음)
  - 새로운 매칭 기회 제공
- **제약**: 게임 진행률 50% 이상일 때만 사용 불가 (선택사항)

#### 되돌리기 (Undo)
- **기능**: 마지막 타일 제거 액션 취소
- **제한**: 게임당 최대 3회
- **제약**: 첫 번째 이동 후부터 사용 가능

### 3.4 점수 시스템

#### 점수 산정
- **기본 점수**: 타일 1쌍 제거 = 10점
- **보너스 점수**:
  - 연속 제거 (콤보): 3번 연속 제거 = +50점
  - 신속 클리어 (시간 보너스): 남은 시간 × 1점
  - 특수 조합 매칭: +25점
- **페널티**: 힌트 사용 시 -10점 (선택사항)

#### 점수 기록
- **하이스코어**: localStorage에 저장
- **게임 결과 표시**: 최종 점수, 달성률, 소요 시간

## 4. 저장 시스템

### 4.1 게임 상태 저장

```json
{
  "gameId": "uuid",
  "timestamp": "ISO8601",
  "layout": "pyramid",
  "tiles": [
    {
      "id": 1,
      "type": "character",
      "number": 1,
      "x": 0,
      "y": 0,
      "zIndex": 10,
      "removed": false
    }
  ],
  "state": {
    "hintsUsed": 1,
    "shuffleUsed": false,
    "undoUsed": 2,
    "score": 450,
    "elapsedTime": 125,
    "remainingTiles": 134
  }
}
```

### 4.2 저장 전략
- **자동 저장**: 타일 제거 시마다 실시간 저장
- **게임 재개**: localStorage에서 진행 상태 복원
- **진행 재개 화면**: "Continue Game" 또는 "New Game" 선택

## 5. UI/UX 명세

### 5.1 주요 화면

| 화면명 | 기능 |
|--------|------|
| **메인 메뉴** | 게임 시작, 진행 중인 게임 계속하기, 규칙 설명 |
| **게임 화면** | 타일 배치, 도구 버튼, 점수 표시, 시간 표시 |
| **게임 결과** | 승리/패배 결과, 최종 점수, 하이스코어, 재시작 |

### 5.2 게임 화면 UI 요소

- **타일 표시 영역** (Canvas 또는 Grid)
  - 마작 타일 136개를 배치
  - 선택된 타일 강조 (색상 또는 테두리)
  - 제거된 타일 페이드아웃 애니메이션

- **도구 버튼 바**
  - "힌트" 버튼 (남은 횟수: 3/3)
  - "셔플" 버튼 (제공 여부: [O] 또는 [X])
  - "되돌리기" 버튼 (남은 횟수: 3/3)
  - "메뉴로" 버튼

- **정보 표시 영역**
  - 현재 점수: 450점
  - 소요 시간: 2:30
  - 남은 타일 수: 134개

### 5.3 타일 디자인

#### 타일 외형
- **크기**: 50×50px (또는 반응형)
- **배경**: 밝은 크림색 또는 흰색
- **테두리**: 진한 갈색 1px
- **아이콘**: 타입별로 구분되는 심볼 (숫자, 바람, 용 등)
- **폰트**: 가독성 높은 폰트 (NotoSans, Arial 등)

#### 타일 상태
- **기본 상태**: 흰색 배경
- **호버 상태**: 배경 밝아짐 (20% 투명도 증가)
- **선택 상태**: 진한 파란색 테두리 (3px)
- **제거 애니메이션**: 스케일 축소 → 페이드아웃 (0.3초)

### 5.4 팝업 및 다이얼로그

- **게임 오버 팝업**: "Game Complete\! Score: 1200"
- **패배 팝업**: "No Moves Available. Remaining: 34"
- **규칙 설명 팝업**: 게임 룰 및 도구 사용법
- **일시정지 팝업**: "Paused - Continue or Back to Menu"

## 6. 렌더링 및 애니메이션

### 6.1 애니메이션 명세

| 효과명 | 타이밍 | 지속시간 |
|--------|--------|----------|
| **타일 제거** | 타일 2개 매칭 후 | 0.3초 |
| **타일 선택 강조** | 클릭 시 | 0.15초 |
| **게임 승리 연출** | 마지막 타일 제거 시 | 1.5초 |
| **점수 플로팅** | 타일 제거 시 | 0.5초 |
| **새로고침 애니메이션** | 셔플 실행 | 1.0초 |
