# Mahjong Zen - Game Design Document

## 1. 게임 컨셉 및 비전

### 1.1 게임 컨셉
**Mahjong Zen**은 전통 마작의 솔리테어 변형으로, 플레이어가 혼자서 136개의 마작 타일을 모두 제거하는 퍼즐 게임입니다. 조용한 명상적 분위기에서 차분하게 문제를 풀어나가는 경험을 제공합니다.

### 1.2 게임의 비전
- **핵심 가치**: "마작의 규칙으로 즐기는 고요한 퍼즐 게임"
- **타겟 플레이어**: 
  - 캐주얼 퍼즐 게임을 즐기는 30-60세 이상 플레이어
  - 명상과 휴식을 추구하는 사용자
  - 마작 규칙에 친숙한 플레이어
- **플레이 방식**: 시간 제한 없는 느슨한 진행, 각자의 속도로 즐길 수 있음
- **장기 목표**: 매일의 챌린지 완료, 하이스코어 갱신, 모든 레이아웃 마스터

### 1.3 슬로건
**"마작 타일의 조용한 세계에서 문제를 풀어보세요."**

## 2. 메카닉 분류

### 2.1 주 메카닉: Puzzle / Mahjong Solitaire

**퍼즐 요소 (Puzzle)**:
- 주어진 타일 배치에서 규칙을 따라 모든 타일을 제거
- 논리적 사고와 패턴 인식이 필수
- 시행착오를 통한 문제 해결
- 정답이 여러 개 존재 가능 (완전 결정론적 아님)

**마작 요소 (Mahjong Solitaire)**:
- 마작의 기본 규칙 (같은 타입 2개 제거 가능)
- 마작 타일 136개의 정확한 구성 준수
- 전통 마작의 실마리를 현대적으로 재해석

**솔로 플레이 요소 (Solitaire)**:
- 싱글 플레이어 경험 (멀티플레이 없음)
- 타이밍 압박 없음 (시간 제한 선택사항)
- 개인의 속도와 사고 방식을 존중

### 2.2 게임 메커니즘의 핵심

1. **타일 제거**: 같은 타입 2개를 선택하여 제거
2. **배치 최적화**: 제거 불가능한 타일 조합을 피해야 함
3. **도구 활용**: 힌트, 셔플로 어려움 극복
4. **점수 관리**: 효율적 제거로 고점수 달성

## 3. 핵심 재미 요소

### 3.1 문제 해결의 재미
- **논리적 도전**: 각 이동이 향후 진행에 영향을 미침
- **가능성 탐색**: "이 타일을 지우면 나중에 문제가 될까?" 고민
- **"Aha\!" 모멘트**: 막혔던 상황을 갑자기 해결할 방법을 발견했을 때의 쾌감

### 3.2 명상적 분위기
- **조용한 배경음**: 잔잔한 음향 효과 (선택사항)
- **시간 압박 없음**: 생각할 만큼의 시간 제공
- **부드러운 색감**: 눈에 편한 UI/색상 설계
- **차분한 시각 효과**: 과도한 애니메이션 최소화

### 3.3 진행의 쾌감
- **명확한 진행도**: 남은 타일 수로 진행률 시각화
- **점진적 보상**: 타일 제거 시마다 점수 증가
- **승리의 쾌감**: 마지막 타일 제거 시 축하 연출

### 3.4 도구의 활용 전략
- **힌트 선택**: 3회라는 제한 속에서 언제 사용할지 결정
- **셔플 타이밍**: 막힌 상황을 타개할 수 있는 기회
- **되돌리기**: 잘못된 선택을 바로잡을 수 있는 안전장치

## 4. 게임플레이 루프

### 4.1 단일 게임 루프 (10-30분)

```
게임 시작 (새 게임 또는 계속하기)
  ↓
타일 배치 확인 및 전략 수립
  ↓
(반복) 
  제거 가능한 타일 쌍 찾기
    ↓
  타일 2개 선택 및 제거
    ↓
  점수 추가, 남은 타일 확인
    ↓
  필요 시 도구 사용 (힌트, 셔플, 되돌리기)
↓
게임 종료 (승리 또는 패배)
  ↓
점수 기록 및 결과 확인
  ↓
재시작 또는 메뉴로
```

### 4.2 세션 루프 (30분 이상)

```
여러 게임 연속 진행
  ↓
점진적으로 난이도 높은 레이아웃 도전
  ↓
하이스코어 갱신 시도
  ↓
세션 종료 (저장)
  ↓
다음 세션 계획
```

## 5. 난이도 설계

### 5.1 게임 난이도 단계

| 난이도 | 타일 배치 | 특징 | 권장 플레이어 |
|--------|---------|------|----------|
| **Beginner** | 피라미드 (간단함) | 제거 가능한 경로 많음, 실수 회복 용이 | 처음 플레이어 |
| **Intermediate** | 동쪽 (중간) | 제거 순서가 중요함, 막힐 가능성 있음 | 경험 있는 플레이어 |
| **Advanced** | 북쪽/벽 (복잡함) | 최적 경로 찾기 어려움, 높은 집중력 필요 | 숙련자 |
| **Daily Challenge** | 랜덤 | 매일 같은 시드의 신규 게임 | 모든 플레이어 |

### 5.2 난이도 조절 메커니즘

- **도구 보상**: 어려울수록 더 많은 도구 제공 (힌트 +1, 셔플 +1)
- **선택 자유도**: 게임을 시작하기 전에 난이도 선택 가능
- **자동 난이도**: 플레이어의 성공률에 따라 다음 게임 난이도 제안
- **스킵 기능**: 너무 어려우면 다음 게임으로 진행 가능 (선택사항)

### 5.3 실패 방지

- **Stalemate 감지**: 제거 불가능한 상태에 도달하기 전에 경고
- **도움말 시스템**: 막혔을 때 자동으로 "힌트 사용?" 제안
- **충분한 도구**: 3회 힌트와 1회 셔플로 대부분의 게임 완주 가능
- **재시작 용이**: "포기" 버튼으로 언제든 새 게임 시작

## 6. 수익화 방안

### 6.1 무료 게임 모델

Mahjong Zen은 기본적으로 **무료 게임**으로 설계되었으나, 다음과 같이 수익화 옵션 제공:

#### A. 광고 기반 (선택적)
- **게임 오버 광고**: 게임 실패 시 광고 시청 → "재시도" 기회 (1회/게임)
- **도구 광고**: 도구 소진 시 광고 시청 → 도구 1회 충전
- **보상 광고**: 일일 보너스 포인트 획득 시 광고 시청

#### B. 구독 모델 (프리미�m)
- **Mahjong Zen+**: 월 2,900원
  - 광고 제거
  - 무제한 힌트 및 셔플
  - 일일 특별 챌린지 추가
  - 통계 및 성과 분석

#### C. DLC (확장 컨텐츠)
- **추가 레이아웃 팩**: 5,900원
  - 10개의 신규 배치 추가
  - 테마 변경 (컬러 팩)
  
#### D. 소량 과금 (IAP)
- **도구 충전**: 100원~
  - 힌트 3회 = 490원
  - 셔플 1회 = 290원
  - 되돌리기 3회 = 390원

### 6.2 수익화 철학

- **본질 보호**: 핵심 게임 플레이는 절대 과금화하지 않음
- **선택성**: 모든 과금은 선택적 (게임 완주에 필수 아님)
- **공정성**: 과금 플레이어가 실력 우위를 갖지 않도록 설계
- **불편함 최소화**: 광고는 거슬리지 않는 타이밍에만 제공

## 7. 차별점 및 경쟁 분석

### 7.1 경쟁사 분석

| 경쟁사 게임 | 장점 | 약점 | 우리의 차별화 |
|-------------|------|------|----------|
| **Mahjong Titans** | 클래식 규칙, 오래된 서비스 | 구식 UI, 과도한 광고 | 현대적 디자인, 최소 광고 |
| **Mahjong Solitaire** | 많은 레이아웃 | 복잡한 진행, 높은 과금 | 간단하고 명확한 시스템 |
| **Microsoft Mahjong** | 정부 공식, 신뢰성 | 제한된 커스터마이징 | 다양한 테마 및 옵션 |
| **Mahjong Quest** | 스토리 요소 | 복잡성, 높은 진입장벽 | 순수 퍼즐 경험 집중 |

### 7.2 우리의 차별점

#### 1. **명확한 게임 철학**
- 마작의 순수한 매력에 집중
- 스토리나 추가 요소로 인한 복잡성 배제
- "덜이 더 많다"는 미니멀리즘 철학

#### 2. **현대적 UI/UX**
- 깔끔한 인터페이스 (플랫 디자인)
- 반응형 레이아웃 (데스크톱, 태블릿, 모바일)
- 다크 모드 지원

#### 3. **명상적 경험**
- 조용한 음향 환경
- 시간 압박 없는 여유 있는 진행
- 시각적 혼란 최소화

#### 4. **공정한 도구 시스템**
- 제한된 힌트 (3회)로 전략성 부여
- 셔플과 되돌리기로 다양한 해결 방법 제공
- 도구 제한이 과도하지 않음

#### 5. **수익화 윤리**
- 무료 게임으로 진입장벽 제거
- 광고는 선택적 (보상형)
- 과금은 편의성 강화만 (게임플레이 변경 없음)

### 7.3 시장 포지셔닝

**타겟 마켓**: 
- 메인: 40-70세 이상 카주얼 게이머
- 서브: 스트레스 해소를 원하는 젊은 성인

**포지셔닝 메시지**:
"마작의 고요한 세계에서 시간 압박 없이 문제를 풀어보세요. 명상 같은 게임 경험을 제공합니다."

**유통 전략**:
1. 웹 버전: itch.io 또는 개인 웹사이트
2. 모바일: iOS App Store, Google Play (추후)
3. 데스크톱: Steam (추후)

## 8. 향후 확장 계획

### 8.1 콘텐츠 확장
- **신규 레이아웃**: 10+ 추가 배치 패턴
- **시즈널 테마**: 계절별 배경 및 타일 디자인
- **역사적 마작 규칙**: 중국 마작, 일본 마작 등 변형 규칙

### 8.2 게임 모드 확장
- **일일 챌린지**: 매일 같은 난이도의 신규 게임
- **토너먼트 모드**: 7일 연속 게임 점수 합산
- **랜덤 시드 모드**: 무한 게임 생성

### 8.3 소셜 기능 (선택적)
- **점수 공유**: SNS 공유 (이미지)
- **온라인 리더보드**: (추후, 선택적)
- **친구 초대**: (추후, 선택적)

### 8.4 접근성 개선
- **음성 안내**: 시각 장애자를 위한 음성 피드백
- **글자 크기 옵션**: 고령자를 위한 조정 가능 UI
- **색각 이상 모드**: 색맹 친화적 팔레트

## 9. 성공 지표

### 9.1 게임 성공 측정

- **일일 활성 사용자 (DAU)**: 1,000명 이상
- **월간 활성 사용자 (MAU)**: 5,000명 이상
- **평균 세션 길이**: 15분 이상
- **일일 재방문율**: 30% 이상
- **게임 완주율**: 60% 이상
- **하이스코어 갱신 시도**: 주 2회 이상

### 9.2 수익 목표

- **월간 수익**: 목표 없음 (무료 게임으로 설계)
- **구독자 수**: 500명 (선택적 구독의 10%)
- **광고 수익**: 월 100-200달러

## 10. 참고 사항

- **규칙 정확성**: 마작의 기본 규칙을 충실히 따름
- **타일 배치**: 각 배치가 항상 해결 가능하도록 검증
- **저장 기능**: 중단 후 복구 가능하도록 설계
- **오프라인 플레이**: 인터넷 없이 완전히 즐길 수 있음
