## Derby Dash 프로토타입 - 게임 디자인 문서

## 게임 컨셉 및 비전

Derby Dash 프로토타입은 **클래식한 경마 게임의 스릴**을 현대적 인터페이스와 함께 제공합니다. 간단하면서도 중독성 있는 배팅 게임으로, 플레이어들이 재운과 전략을 모두 경험할 수 있도록 설계되었습니다.

비전: "누구나 즐길 수 있는 가벼운 경마 시뮬레이션에서 시작하여, 향후 고급 통계 분석 플랫폼으로 확장"

## 메카닉 분류

**Racing / Betting Simulation**

실시간 경주 시뮬레이션과 파리뮤추얼 배팅 시스템을 결합한 경마 게임입니다. 우연성과 전략성의 밸런스를 통해 각 게임의 긴장감과 흥미를 극대화합니다.

## 핵심 재미 요소

### 1. 불확실성과 스릴
- 매 경주마다 다른 결과
- 약체마의 역전승 가능성
- 배당률 변동에 따른 긴장감

### 2. 경제 시뮬레이션
- 뱅크롤 관리 전략
- 베팅액 결정의 중요성
- 리스크 vs 보상의 선택

### 3. 시각적 만족감
- 말들의 실시간 애니메이션
- 먼지 파티클 이펙트
- 우승 순간의 카타르시스

### 4. 청각적 피드백
- 출발 신호음의 긴장감
- 갤럽 리듬의 속도감
- 승리의 쾌감 (팡파르)

### 5. 반복 재미성
- 짧은 게임 시간 (2-3분/경주)
- 즉각적인 결과 피드백
- "한판 더" 심리 유도

## 게임플레이 루프

### 메인 루프 구조
```
[시작 메뉴]
    ↓
[베팅 단계] → 말 선택 및 베팅액 결정
    ↓
[경주 진행] → 실시간 말 이동 애니메이션
    ↓
[결과 판정] → 우승마 확인 및 배당금 계산
    ↓
[상금 수령] → 뱅크롤 업데이트
    ↓
[다음 경주] → 루프 반복 또는 종료
```

### 게임 단계별 플레이 패턴

**BeGin (시작 단계)**: 초기 $1,000 자본 할당

**Betting (베팅 단계)**:
1. 9마리 말 중 1마리 선택
2. 칩 버튼으로 베팅액 결정 ($10~$500)
3. 현재 베팅액 및 예상 배당금 표시
4. "경주 시작" 버튼 클릭

**Racing (경주 단계)**:
1. 출발 신호음
2. 각 말이 고유한 속도로 트랙 이동
3. 실시간 갤럽 사운드
4. 리얼타임 위치 업데이트

**Result (결과 단계)**:
1. 우승마 발표
2. 배당금 계산 표시
3. 최종 뱅크롤 업데이트
4. 다음 경주 준비

### 3. 시즌 패스
- 월간 이벤트 참여
- exclusive 말 캐릭터
- 프리미엄 스킨 및 이펙트

- 영상 광고 시청으로 보너스 칩

## 균형 설계

### 말의 능력치 분포
- 빠른 말: 높은 기본 속도, 낮은 지구력
- 느린 말: 낮은 기본 속도, 높은 지구력
- 평균적 말: 중간 능력치

### 배당률 조정
- 높은 배당률: 저확률의 말 → 높은 수익
- 낮은 배당률: 고확률의 말 → 낮은 수익
- 동적 조정: 베팅 풀에 따라 실시간 변동

### 난이도 곡선
- 초반: 다양한 결과로 학습 유도
- 중반: 안정적 수익 기대
- 후반: 전략적 베팅 필수

## 기술적 특성

### 성능 목표
- 60 FPS 유지 (부드러운 애니메이션)
- 100ms 이내 반응 시간
- 메모리 사용량 < 50MB

- LocalStorage (저장)
- 반응형 디자인

### 접근성
- 키보드 조작 지원
- 컬러 블라인드 모드
- 음성 안내 옵션
