# Gravity Flip - 게임 디자인 문서 (Game Design Document)

## 1. 게임 컨셉 및 비전

### 1.1 핵심 컨셉
**한 번의 탭으로 벗어나는 무한 스릴 경험**

Gravity Flip는 단 하나의 조작(탭/스페이스바)으로 중력을 반전시키며, 끊임없이 다가오는 벽들을 피하는 극단적으로 단순하면서도 중독성 강한 원버튼 서바이벌 게임입니다.

### 1.2 게임 비전
- **단순성**: 배우기 5초, 마스터하기 무한대
- **즉시성**: 페이드 없이 바로 플레이 시작, 죽으면 0.7초 후 다시 시작
- **반사 신경**: 플레이어의 순간 판단과 손가락 속도가 승패를 결정
- **중독성**: 계속 재시도하게 만드는 심리적 보상 시스템

### 1.3 플레이 경험
```
초기 학습(30초) → 몰입(1~3분) → 도전(5분+) → 재시작
```

## 2. 메카닉 분류

### 2.1 장르 정의
- **1차 장르**: Arcade / Endless Runner
- **2차 장르**: One-Button Survival / Reflexes Game
- **서브 카테고리**: Casual / Hypercasual (IAP 포함)

### 2.2 메카닉 원소
| 메카닉 | 설명 | 영향력 |
|--------|------|--------|
| **중력 반전** | 단일 입력으로 중력 벡터 180도 반전 | 핵심 |
| **자동 진행** | 벽이 자동으로 화면을 지나감 | 핵심 |
| **충돌 감지** | 벽과의 접촉 즉시 게임 오버 | 핵심 |
| **난이도 곡선** | 점수 기반 동적 난이도 상승 | 중요 |
| **점수 시스템** | 벽 통과(+1), 골드 오브(+5) | 중요 |
| **파티클 이펙트** | 시각적 피드백 (탭, 충돌, 수집) | 보조 |
| **최고점수 추적** | localStorage 기반 재방문 유도 | 보조 |

## 3. 타겟 유저

### 3.1 프라이머리 타겟
- **연령대**: 13~35세
- **성별**: 남/녀 (남성 60%, 여성 40%)
- **플레이 스타일**: 캐주얼 - 한 판에 2~5분
- **게임 경험**: 비디오 게임 경험 필수 아님 (완전 초심자도 5초면 이해)
- **플레이 환경**: 모바일(95%), PC/웹(5%)

### 3.2 세컨더리 타겟
- **스트리머/유튜버**: 짧은 영상 콘텐츠 제작용
- **경쟁 게이머**: 하이스코어 리더보드 경쟁
- **중독성 게임 팬**: Flappy Bird, 2048 유형의 게임 즐기는 유저

### 3.3 플레이 패턴
- **세션 1**: 처음 발견 → 2~3판 플레이 → 떠남
- **세션 2**: 재방문 시도 → 최고점수 갱신 욕구 → 10~20판 집중
- **세션 3+**: 일일 1~2회 챌린지 플레이 → 스코어 경쟁

## 4. 핵심 재미 요소

### 4.1 코어 루프 (Core Loop)

```
┌─────────────────────────────────────┐
│  벽 등장 (화면 우측)                  │
│  플레이어: 상단 또는 하단           │
└──────────┬──────────────────────────┘
           │
           ▼
┌─────────────────────────────────────┐
│  플레이어 판단: 이 벽을 통과할 수    │
│  있는가? 어느 쪽으로 이동할가?       │
└──────────┬──────────────────────────┘
           │
           ▼
┌─────────────────────────────────────┐
│  탭/스페이스바 입력 (또는 비입력)     │
│  중력 반전 → 플레이어 이동           │
└──────────┬──────────────────────────┘
           │
           ▼
    ┌──────┴──────┐
    ▼             ▼
┌──────────┐   ┌──────────┐
│ 충돌\!    │   │ 통과 OK\! │
│ 게임오버 │   │ +1 점수  │
└──────────┘   └──────────┘
                    │
                    ▼
         ┌────────────────────┐
         │ 다음 벽 등장       │
         │ 난이도 상승        │
         │ (속도↑, 간격↓)     │
         └────────────────────┘
```

### 4.2 심리적 장치

#### 순간적 결정
- 벽이 나타나고 판단/입력까지 **0.5~1초** 윈도우
- 뇌의 의사결정 속도 극대화
- 성공 시: "내 반응이 좋아" 쾌감
- 실패 시: "아, 그냥 0.7초 후 재시작" 낮은 좌절감

#### 점진적 도전
- 처음 10판은 여유로움 (학습 곡선)
- 10~50판에서 점진적 난이도 상승
- 50판 이상에서 극한의 반사 신경 요구
- "다시 한판만" 심리 → 끝없는 재시도 루프

#### 시각적 보상
- 벽 통과 → 파티클 펑펑 (그린 이펙트)
- 골드 오브 수집 → 황색 폭발 + 점수 5배
- 탭 입력 → 시안 파티클 (반응 피드백)
- 충돌 → 빨간 폭발 (극적 연출)

#### 최고점수 기록
- 게임 시작 시 "BEST: [점수]" 표시
- 갱신의 쾌감 → 재방문 강제
- 친구보다 높은 점수 경쟁 심리

### 4.3 중독성 메커니즘

#### 1. 낮은 마찰
- 배우기 간단: 5초
- 입력 1개: 탭
- 시작까지 시간: 거의 0초

#### 2. 빠른 피드백
- 입력 → 즉시 중력 반전 (지연 0ms)
- 충돌 → 즉시 게임 오버 (지연 0ms)
- 점수 증가 → 실시간 표시

#### 3. 무한 재시작
- 게임오버 후 0.7초 자동 재시작
- 또는 탭으로 즉시 재시작
- "한 판 더" 심리 강화

#### 4. 난이도 곡선
- 초반 승률 높음 (학습 보상)
- 후반 실패율 높음 (도전 욕구)
- "저 벽은 꼭 통과할 수 있을 것 같은데" 착각 유도

#### 5. 사회적 경쟁
- 최고점수 공개 (자신의 기록)
- 향후: 온라인 리더보드 (타인과 비교)
- 친구 초대 가능 (바이럴 확산)

## 6. 난이도 설계 철학

### 6.1 난이도 곡선 이론

#### "The Skill-Challenge Balance" (칙센트미하이의 몰입 이론)
```
                       난이도 (Challenge)
                              ▲
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
        │                 몰입 영역                  │
        │                  (Flow)                   │
        │                     │                     │
플레이어├─────────────────────╋─────────────────────┤
기술도  │                     │                     │
        │                 불안 영역                 │
        │                     │                     │
        │                 지루 영역                 │
        └─────────────────────┼─────────────────────┘
                              │
                              └────────────────────▶
                           플레이어 기술
```

### 6.2 점수 구간별 난이도 정책

#### Phase 1: 학습 구간 (0~10점, 약 2분)
- **목표**: 게임 규칙 이해, 플레이 자신감 확보
- **벽 속도**: 220px/s (매우 느림)
- **간격 높이**: 180px (넓음)
- **생성 간격**: 1.4초 (여유 있음)
- **체감**: "어? 이게 다야?" → "나 잘하는데?"
- **전략**: 거의 생각할 시간 있음

#### Phase 2: 중급 구간 (10~30점, 약 3~5분)
- **목표**: 반응 속도 향상, 지루함 해소
- **벽 속도**: 270px/s (점진적 증가)
- **간격 높이**: 180→140px (줄어듦)
- **생성 간격**: 1.2초 (압박감)
- **체감**: "어? 빨라졌네? 하지만 할 수 있어"
- **전략**: 직관적 판단 필수

#### Phase 3: 상급 구간 (30~50점, 약 5~8분)
- **목표**: 극한 순간의 스릴, 거의 실패 직전
- **벽 속도**: 370px/s (매우 빠름)
- **간격 높이**: 140→100px (매우 좁음)
- **생성 간격**: 0.9초 (거의 쉬지 않음)
- **체감**: "이제 정말 어렵다... 근데 한 판만 더"
- **전략**: 반사 신경과 운도 필요

#### Phase 4: 극난이도 (50+점, 장수 플레이)
- **목표**: 거의 불가능한 도전, "나 이 정도까지 가능해?" 자부심
- **벽 속도**: 440px/s (캡핑)
- **간격 높이**: 100px (최소, 고정)
- **생성 간격**: 0.6초 (최소)
- **체감**: "미쳤다... 이걸 통과했다고?"
- **전략**: 100% 반사 신경 + 운

### 6.3 난이도 상승 알고리즘

```
현재_점수 = C (예: 35점)

속도 = MIN(220 + (C / 10) * 30, 440)
     = MIN(220 + 3.5 * 30, 440)
     = MIN(220 + 105, 440)
     = MIN(325, 440)
     = 325 px/s

간격높이 = MAX(180 - (C / 20) * 20, 100)
        = MAX(180 - 1.75 * 20, 100)
        = MAX(180 - 35, 100)
        = MAX(145, 100)
        = 145px

생성간격 = MAX(1.4 - (C / 50) * 0.8, 0.6)
       = MAX(1.4 - 0.7 * 0.8, 0.6)
       = MAX(1.4 - 0.56, 0.6)
       = MAX(0.84, 0.6)
       = 0.84초
```

## 7. 재방문 유도 전략

### 7.1 장시간 도파민 회로

#### 즉각적 보상
- **승리**: 벽 통과 → 파티클 이펙트 + 음성 피드백
- **실패**: 충돌 → 빨간색 폭발 + 극적 게임오버 화면
- **회피 심리**: 실패의 고통을 0.7초 후 자동 재시작으로 중화

#### 누적 점수
- 한 판의 점수 합: 10~50점 (평균 20점)
- 누적할수록 높아지는 난이도 → 실패 불가피 → 특정 점수 달성의 희소성
- "어제는 50점을 못 넘었는데, 오늘은?" 재도전 욕구

#### 최고점수 기록
- localStorage에 자동 저장 (계정 필요 없음)
- 게임 시작 시 "BEST: [기록]" 시각적 압박
- "내 기록을 깨야 한다" 심리

### 7.2 단기 재방문 (세션 내)

| 시간 | 액션 | 심리 |
|------|------|------|
| 0초 | 게임 시작 | 새로운 시도 |
| 1분 | 첫 죽음 (5점) | 아, 이 정도야 |
| 3분 | 20점 달성 | 오, 꽤 잘하는데? |
| 5분 | 실패 반복 (15~25점) | 한 판만 더... |
| 7분 | 운이 좋아서 35점 | 오\! 내 최고 기록 근처\! |
| 8분 | 실패 → 자동 재시작 | 아 너무 아깝다, 한 판만 더 |
| 10분 | 최대 50점 달성 | 오스\! 내 기록이다\! |

→ **평균 세션 길이**: 10~15분, 약 50~100판 플레이

### 7.3 장기 재방문 (일간/주간)

#### 일일 플레이
- **패턴**: 아침 2~3판 + 점심 3~5판 + 저녁 5~10판
- **누적 시간**: 일 30분~1시간
- **유지 메커니즘**: 어제 기록 갱신 욕구

#### 주간 플레이
- **목표**: 주 최고점수 달성 (SNS 공유 욕구)
- **경쟁 심리**: 친구들과 스코어 비교 (향후 온라인 리더보드)
- **밀리세컨드 경쟁**: 50점 달성한 사람들의 "몇 밀리초 더 나아가면 60점도 가능할 것 같은데" 심리

### 7.4 광고 기반 재방문

#### 연속 사망 패턴
- 3회 연속 사망 → 전면 광고 노출
- 광고 후 → 기분 나쁨 → 보상 광고 보기
- 보상 광고 보면 체력/생명 1회 추가 (향후 시스템)
- → "내가 광고를 봤으니 한 판 더" 심리

#### 수익화와의 균형
- 1~2판 당 광고 1회 (과하지 않음)
- 광고로 인한 중단감 → "구매하면 광고 제거" 신호
- IAP: 광고 제거 + 캐릭터 스킨 + 난이도 조정

## 8. 수익화 방안

### 8.1 광고 기반 수익 (주요 수익원: 70%)

#### 인터스티셜 광고 (전면 광고)
- **발생 조건**: 3회 연속 사망 또는 매 5판마다
- **노출 시간**: 5초 강제 시청
- **eCPM**: 약 2~5 USD (지역별)
- **예상 RPM**: 하루 1000명 × 50판 × (1/5) = 약 10,000 회 노출
- **일일 예상 수익**: 10,000 × 0.003 = 약 $30~50

#### 리워드 광고 (보상형 광고)
- **발생 조건**: 게임오버 화면에서 "한 번 더 플레이하기" 선택
- **보상**: 체력 1회 복구 또는 난이도 -1 (향후 시스템)
- **시청**: 자발적 (강제 아님)
- **eCPM**: 약 5~15 USD (높은 참여도)
- **예상 클릭율**: 50명 중 5~10명 (10~20%)
- **일일 예상 수익**: 500 리워드 × 0.008 = 약 $4~8

#### 배너 광고 (선택사항)
- **위치**: 게임 상단 또는 하단 (게임플레이 방해 X)
- **eCPM**: 약 0.5~1 USD (낮음)
- **클릭율**: 매우 낮음 (1% 이하)
- **일일 예상 수익**: 약 $1~2

**월간 광고 수익**: ($40 / 일) × 30 = 약 $1,200

### 8.2 In-App Purchase (IAP: 20%)

#### 광고 제거 (한 번 구매, 영구)
- **가격**: $0.99 ~ $2.99 (지역별)
- **전환율**: 2~5% (평균 3%)
- **일일 신규 사용자**: 1,000명
- **구매 사용자**: 30명
- **일일 수익**: 30 × $1.99 = $59.70

#### 캐릭터 스킨 (미래 시스템)
- **가격**: $0.99 (각각)
- **스킨 개수**: 6가지 (기본 + 5가지 구매)
- **전환율**: 2% (평균)
- **구매 사용자**: 20명
- **일일 수익**: 20 × $0.99 = $19.80

#### 테마 팩 (보조)
- **가격**: $1.99
- **전환율**: 1%
- **일일 수익**: 약 $10

**월간 IAP 수익**: ($60 + $20 + $10) × 30 = 약 $2,700

## 9. 경쟁 분석 및 차별점

### 9.1 경쟁사 분석

#### Flappy Bird (2013)
- **장점**: 단순한 게임플레이, 중독성
- **단점**: 2014년 앱 스토어에서 삭제, 이제는 회상만
- **우리의 차별점**: 여전히 활발한 게임, 현대적 수익화

#### 2048 (2014)
- **장점**: 매우 단순한 규칙, 전략 요소
- **단점**: 한 번 이해하면 스킬 차이 적음
- **우리의 차별점**: 순수 반사 신경 게임, 계속 도전 유인

#### Tappy Plane / Plane Runner
- **장점**: Flappy Bird 클론으로 일부 성공
- **단점**: 원본 이상의 혁신 없음
- **우리의 차별점**: 중력 반전이라는 독특한 메카닉

#### Geometry Dash (2013)
- **장점**: 리듬감, 아트 스타일, 레벨 에디터
- **단점**: 게임플레이가 Flappy와 유사, 복잡도 높음
- **우리의 차별점**: 극도로 단순함 + 더 빠른 피드백

## 결론

Gravity Flip는 **극도의 단순함**과 **높은 중독성**을 결합한 캐주얼 아케이드 게임으로, 핵심 메카닉인 "중력 반전"을 통해 Flappy Bird 수준의 시장 영향력을 목표로 합니다.

**핵심 성공 요인**:
1. 5초 안에 배울 수 있는 게임플레이
2. 무한 재시작 루프를 통한 "한 판 더" 심리
3. 점진적 난이도 상승으로 인한 중독성
4. 최고점수 추적 및 재방문 유도
5. 최적화된 수익화 모델 (광고 + IAP)

**출시 및 성장**:
- MVP (1주) → v1.0 (1개월) → v2.0 (3개월)
- 월간 10,000 DAU 달성 기대
- 월간 $5,000 순 수익 목표 (연간 $60,000+)
