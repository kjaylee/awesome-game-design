## Derby Dash 데이터 분석 플랫폼 - 게임 디자인 문서

## 게임 컨셉 및 비전

Derby Dash는 순수한 경마 게임을 넘어선 **데이터 드리븐 게임 운영 플랫폼**입니다. 경마 데이터를 수집, 분석, 시각화하는 과정 자체를 자동화하며, 게임의 운영자들이 의사 결정을 데이터 기반으로 내릴 수 있도록 지원합니다.

## 메카닉 분류

**Racing / Data Platform**

경마라는 핵심 게임 장르에 데이터 분석 및 자동화 플랫폼 기능을 결합한 하이브리드 게임 운영 시스템입니다.

## 핵심 재미 요소

### 1. 자동화의 효율성
- 반복적인 데이터 수집 작업 자동화
- 한 번의 명령으로 전체 파이프라인 실행
- 시간 절약과 인적 오류 감소

### 2. 데이터 통찰
- 패턴 인식 및 트렌드 분석
- 통계 기반 의사 결정
- 과거 데이터로부터 미래 예측

### 3. 투명성 및 신뢰성
- 모든 데이터 수집 과정 기록 및 추적
- 분석 결과의 재현성 보장
- 객관적 기반의 의사 결정 지원

## 게임플레이 루프

```
데이터 수집 (Research)
    ↓
검색 인덱스 생성 (Index)
    ↓
통계 분석 (Analyze)
    ↓
정보지 초안 생성 (Generate Reports)
    ↓
결과 검증 및 피드백
    ↓
반복
```

### 각 단계의 역할

**Research 단계**: 외부 소스에서 경마 데이터 자동 크롤링 및 수집

**Index 단계**: 수집된 데이터를 빠른 검색을 위해 인덱싱

**Analyze 단계**: 통계 분석을 통해 인사이트 도출

**Generate 단계**: 자동 분석 보고서 및 정보지 생성

- 월/연 구독 모델

### 2. API 접근권
- 경마 데이터 API 유료 접근
- 분석 결과 데이터 판매
- 파트너사 연계

### 3. 프리미엄 분석 기능
- 고급 통계 분석
- 예측 모델 제공
- 맞춤형 리포팅

### 4. 광고 및 후원
- 정보지 내 광고 게재

## 기술 스택 및 배포 전략

### 기술 스택
- TypeScript: 타입 안전한 개발
- Node.js: 백엔드 런타임
- GitHub Pages: 정적 사이트 호스팅
- npm: 패키지 및 스크립트 관리

### 확장성
- 마이크로서비스 아키텍처 고려
- 데이터베이스 확장 (현재: 파일 기반 → SQL DB)
- API 서버 분리 (향후 추가)

- 사용자 만족도: 4.5/5.0 이상
- 월 활성 사용자 (MAU) 성장률: 20% 이상
