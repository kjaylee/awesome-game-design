# Rhythm Pulse Prototype - Functional Specification

## 1. 게임 개요

**게임명**: Rhythm Pulse — Golden Arcade
**형식**: 단일 HTML5 파일
**장르**: 3레인 리듬 게임
**핵심 목표**: 음악의 비트에 맞춰 노트를 클릭하여 점수 획득

## 2. 기술 스택

| 항목 | 상세 |
|------|------|
| 플랫폼 | HTML5 (단일 파일) |
| 개발 언어 | JavaScript (Vanilla) + Canvas API |
| 오디오 | Web Audio API (절차적 비트 생성) |
| 그래픽 | Canvas 기반 2D 렌더링 |
| 애니메이션 | RequestAnimationFrame |
| 저장소 | localStorage (하이스코어 기록) |
| 배포 | games.eastsea.xyz/rhythm-pulse |

## 3. 핵심 게임 시스템

### 3.1 레인(Lane) 시스템

#### 레인 구성
- **총 레인 수**: 3개 (좌/중/우)
- **레인 배치**:
  ```
  LEFT   CENTER  RIGHT
  [1]     [2]     [3]
  ```
- **레인 너비**: canvas 폭의 1/3 (반응형)
- **히트존 위치**: canvas.height × 0.82 (하단 82% 위치)

#### 히트존 (Hit Zone)
- **위치**: 화면 하단 근처 (y = canvas.height × 0.82)
- **크기**: 너비 (레인 너비) × 높이 (50px)
- **색상**: 반투명 흰색 (30% 투명도)
- **경계**: 강조 테두리 (2px)

### 3.2 노트(Note) 시스템

#### 노트 구성
- **노트 타입**: 일반 노트 (탭 타입, 홀드 타입은 추후)
- **노트 속성**:
  - `id`: 고유 ID
  - `lane`: 레인 (0=LEFT, 1=CENTER, 2=RIGHT)
  - `time`: 노트 떨어지는 시간 (ms)
  - `color`: 색상 (RGB)
  - `status`: idle / hit / missed

#### 노트 스폰(Spawn)
- **스폰 위치**: 화면 상단 (y = 0)
- **폴 속도**: 고정 또는 BPM 기반
  ```
  fallSpeed = (hitY / totalFallTime)
  totalFallTime = 2000ms (기본값)
  ```
- **절차적 생성**: Web Audio API로 비트 분석 후 노트 자동 생성

### 3.3 타이밍 판정 시스템

#### 판정 윈도우 (ms)
```
Perfect: ±100ms (중앙 ±100ms)
Great:   ±200ms (중앙 ±200ms)
Good:    ±300ms (중앙 ±300ms)
Miss:    > ±300ms 또는 미입력
```

#### 점수 산정
| 판정 | 기본 점수 | 콤보 배수 | 최대 점수 |
|------|---------|---------|---------|
| **Perfect** | 100점 | x1 ~ x8 | 800점 |
| **Great** | 75점 | x1 ~ x8 | 600점 |
| **Good** | 50점 | x1 ~ x8 | 400점 |
| **Miss** | 0점 | x1 | 0점 |

#### 콤보 시스템
- **콤보 카운트**: Perfect 또는 Great 판정 시 +1
- **콤보 리셋**: Good 판정 또는 Miss 시 0으로 리셋
- **콤보 배수**: 콤보 수에 따라 점수 배수 증가 (1콤보당 x0.5 증가)
  ```
  multiplier = 1 + (combo / 20)
  최대 x8 (콤보 140+)
  ```

### 3.4 피버(Fever) 모드 시스템

#### 피버 활성화
- **조건**: 콤보 20 이상 달성
- **효과**: 이후 모든 노트의 점수 2배
- **표현**: 화면 배경 색상 변경, 파티클 이펙트 증가

#### 피버 지속
- **유지**: 콤보가 유지되는 동안 계속 활성화
- **해제**: 콤보 리셋 시 피버 모드 종료
- **시각 피드백**: "FEVER" 텍스트 및 아이콘 표시

### 3.5 게임 진행 시스템

#### 게임 시작
- **초기화**: 레인 3개, 히트존 설정
- **음악 로드**: Web Audio API로 절차적 비트 생성
- **노트 생성**: BPM 분석 및 비트 타이밍에 따라 노트 자동 배치

#### 게임 진행
1. 음악 재생 시작
2. 노트 폴 시작 (상단에서 하단으로)
3. 플레이어 타이밍에 맞춰 클릭 또는 키 입력
4. 판정 및 점수 계산
5. 콤보/피버 상태 업데이트
6. 화면 진동 및 파티클 이펙트 발동

#### 게임 종료
- **조건**: 모든 노트 처리 + 음악 종료
- **결과 화면**: 최종 점수, 정확도, 콤보 정보 표시
- **하이스코어 저장**: localStorage에 기록

### 3.6 입력 시스템

#### 입력 방식
- **마우스 클릭**: 각 레인 클릭
- **키보드**: 좌측 (A/←), 중앙 (S/↓), 우측 (D/→)
- **터치**: 모바일 기기 터치 입력

#### 입력 판정
```
inputTime = 현재 시간
noteTime = 노트의 타이밍
timeDiff = |inputTime - noteTime|

if timeDiff <= 100ms:    판정 = "Perfect"
else if timeDiff <= 200ms:  판정 = "Great"
else if timeDiff <= 300ms:  판정 = "Good"
else:                   판정 = "Miss"
```

## 4. 음악 및 절차적 비트 생성

### 4.1 Web Audio API 기반 비트 생성

#### 음악 생성
- **오실레이터**: Sine, Square, Sawtooth 파형
- **ADSR 엔벨로프**: Attack/Decay/Sustain/Release
- **BPM**: 120 BPM (기본값, 가변 가능)
- **박자**: 4/4 박자

#### 절차적 노트 생성
```
for (beat = 0; beat < totalBeats; beat++) {
  time = beat * (60000 / BPM) // 비트당 시간(ms)
  lane = (beat % 3) // 0-2 레인에 순환 배치
  notes.push({
    time: time,
    lane: lane,
    color: getLaneColor(lane)
  })
}
```

#### 난이도별 노트 밀도
| 난이도 | 노트 밀도 | BPM | 비고 |
|--------|---------|-----|------|
| **Easy** | 낮음 (1/2 비트) | 100 | 초보자용 |
| **Normal** | 중간 (1 비트) | 120 | 표준 |
| **Hard** | 높음 (2 비트) | 140 | 숙련자용 |

## 5. 시각 효과 및 애니메이션

### 5.1 파티클 시스템

#### 판정 파티클
- **Perfect**: 황금색 별 (5-7개)
- **Great**: 파란색 별 (3-5개)
- **Good**: 초록색 별 (2-3개)
- **Miss**: 빨간색 X (1개)

#### 파티클 속성
- **이동**: 상향 + 확산 (원뿔 형태)
- **페이드**: 선형 감소 (0.5초)
- **크기**: 10px → 2px (축소)

#### 파티클 생성 위치
- 히트존 중앙

### 5.2 화면 효과

#### 화면 진동 (Screen Shake)
- **트리거**: Perfect 판정, 콤보 20 달성
- **진동 강도**: 5px (Perfect), 10px (콤보)
- **지속시간**: 150ms

#### 배경 색상 변경
- **기본**: 검정색 (#000000)
- **Perfect 시**: 화면 플래시 (흰색, 50ms)
- **피버 모드**: 배경 그라디언트 (황금색 → 보라색)

#### 화면 글로우
- **피버 모드**: 외곽에 황금색 글로우
- **콤보**: 콤보 수에 따라 글로우 강도 증가

### 5.3 UI 애니메이션

#### 점수 플로팅
- **위치**: 히트존에서 상향 이동
- **텍스트**: 판정 텍스트 + 점수 (예: "Perfect +100")
- **색상**: 판정 색상 (황금색, 파란색 등)
- **지속시간**: 0.8초

#### 콤보 표시
- **텍스트**: "COMBO: 50"
- **색상**: 콤보 수에 따라 색상 변경
  - 낮음 (1-10): 흰색
  - 중간 (10-30): 노란색
  - 높음 (30+): 황금색
- **크기 애니메이션**: 콤보 증가 시 스케일 업/다운 (1.0 → 1.3 → 1.0, 0.2초)

## 6. UI/UX 명세

### 6.1 주요 화면

| 화면명 | 기능 |
|--------|------|
| **메인 메뉴** | 게임 시작, 하이스코어, 설정 |
| **게임 화면** | 3레인, 노트, 히트존, 점수/콤보 표시 |
| **게임 결과** | 최종 점수, 정확도, 하이스코어, 재시작 |

### 6.2 게임 화면 UI 요소

- **상단 정보 표시**:
  - 현재 점수 (실시간 업데이트)
  - 콤보 카운트 (색상 변화)
  - 정확도율 (Perfect/Great/Good/Miss 비율)

- **중앙 게임 영역**:
  - 3개 레인 (좌/중/우)
  - 각 레인에 낙하하는 노트
  - 하단 히트존 (강조 테두리)

- **하단 상태 표시**:
  - 남은 노트 개수
  - 음악 진행률 (진행 바)
  - 피버 모드 활성 표시

### 6.3 노트 디자인

#### 노트의 외형
- **모양**: 동그란 원형 (circle)
- **크기**: 반지름 20px (또는 레인 너비의 20%)
- **색상**: 레인별 구분 색상
  - 좌측 (LEFT): 파란색 (#3366FF)
  - 중앙 (CENTER): 노란색 (#FFFF33)
  - 우측 (RIGHT): 빨간색 (#FF3333)
- **테두리**: 2px, 밝은 색 (반투명)

#### 노트의 상태
- **폴링 중**: 기본 색상 + 약간의 빛 효과
- **히트존 진입**: 테두리 강조 (3px)
- **히트 완료**: 폭발 이펙트 (스케일 축소 + 페이드)
- **미스**: 어둡게 표시 후 사라짐

## 7. 렌더링 및 애니메이션

### 7.1 렌더링 루프

```javascript
function gameLoop(currentTime) {
  // 1. 노트 업데이트 (위치 계산)
  updateNotes(currentTime)
  
  // 2. 입력 처리
  handleInput()
  
  // 3. 판정 및 점수 계산
  evaluateNotes()
  
  // 4. 화면 렌더링
  clearCanvas()
  drawBackground()
  drawLanes()
  drawNotes()
  drawHitZone()
  drawUI()
  drawParticles()
  drawEffects()
  
  // 5. 다음 프레임 요청
  requestAnimationFrame(gameLoop)
}
```
