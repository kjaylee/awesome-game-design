# Rhythm Pulse Prototype - Game Design Document

## 1. 게임 컨셉 및 비전

### 1.1 게임 컨셉
**Rhythm Pulse: Golden Arcade**는 3개의 레인에서 떨어지는 노트를 음악의 비트에 맞춰 클릭하는 리듬 게임입니다. 절차적으로 생성된 음악과 노트로 매번 새로운 경험을 제공하며, 네온 비주얼과 피버 모드로 중독성 있는 아케이드 게임 경험을 선사합니다.

### 1.2 게임의 비전
- **핵심 가치**: "음악 리듬과 화려한 비주얼의 완벽한 조화"
- **타겟 플레이어**: 
  - 리듬 게임 팬 (10-35세)
  - 아케이드 게임 향수가 있는 플레이어
  - 중독성 있는 캐주얼 게임을 원하는 사용자
- **플레이 방식**: 5-10분 단위 짧은 세션, 무한 재도전 가능
- **장기 목표**: 어려운 난이도 마스터, 하이스코어 경신, 특수 업적 달성

### 1.3 슬로건
**"리듬에 맞춰, 음악과 함께, 황금 아케이드의 중독성을 느껴보세요\!"**

## 2. 메카닉 분류

### 2.1 주 메카닉: Rhythm / Tap Timing

**리듬 요소 (Rhythm)**:
- 음악의 비트 시간에 정확하게 맞춰 노트를 처리
- 절차적 비트 생성으로 매번 다른 음악 경험
- 시간 정확성이 점수에 직접 영향

**탭 타이밍 요소 (Tap Timing)**:
- Perfect/Great/Good/Miss 타이밍 판정
- ±300ms 윈도우 내에서 입력 유효성 판정
- 정확할수록 높은 점수

**아케이드 요소**:
- 네온 비주얼과 파티클 이펙트
- 콤보 시스템으로 연쇄성 장려
- 피버 모드로 고조되는 쾌감

### 2.2 게임 메커니즘의 핵심

1. **노트 폴링**: 화면 상단에서 하단 히트존으로 노트 낙하
2. **타이밍 판정**: 정확한 시간에 클릭한 정도에 따라 판정
3. **콤보 축적**: Perfect/Great 판정으로 콤보 증가
4. **피버 활성화**: 콤보 20 이상에서 점수 2배

## 3. 핵심 재미 요소

### 3.1 타이밍의 쾌감
- **Perfect 판정**: 정확하게 맞췄을 때의 만족감
- **즉시 피드백**: 판정과 점수가 즉시 표시됨
- **타이밍 도전**: 점점 어려워지는 리듬에 도전

### 3.2 리듬감의 중독성
- **음악과의 싱크로**: 노트가 정확하게 음악 비트에 맞춤
- **절차적 음악**: 매번 다른 비트 생성으로 반복성 극복
- **BPM 변화**: 난이도에 따라 빠른 리듬 체험

### 3.3 콤보 시스템의 긴장감
- **콤보 축적**: 미스 한 번이 모든 콤보를 잃음
- **콤보 카운터 시각화**: 증가하는 콤보 수의 시각적 표현
- **점수 배수**: 높은 콤보일수록 더 높은 점수 획득

### 3.4 피버 모드의 카타르시스
- **피버 활성**: 콤보 20 달성 시 점수 2배
- **화면 이펙트**: 배경 색상 변화, 파티클 폭증, 화면 글로우
- **쾌락의 절정**: 피버 모드 중 콤보 유지의 긴장감

### 3.5 네온 비주얼의 매력
- **화려한 색상**: 주황/보라/파란 네온 색상
- **파티클 폭발**: 판정마다 떨어지는 별 파티클
- **화면 진동**: Perfect 판정 시 화면 떨림
- **눈이 즐거운 경험**: 시각적 자극이 중독성을 강화

## 4. 게임플레이 루프

### 4.1 단일 게임 루프 (5-10분)

```
게임 시작
  ↓
음악 재생 + 노트 폴 시작
  ↓
(반복)
  노트가 히트존 진입
    ↓
  플레이어 클릭
    ↓
  타이밍 판정 (Perfect/Great/Good/Miss)
    ↓
  점수 추가, 콤보 업데이트
    ↓
  필요 시 파티클/이펙트 발동
    ↓
  필요 시 피버 모드 활성/해제
↓
음악 종료, 게임 끝
  ↓
최종 점수 및 하이스코어 비교
  ↓
재시작 또는 메뉴로
```

### 4.2 세션 루프 (30분 이상)

```
여러 게임 연속 진행
  ↓
난이도별 하이스코어 갱신 시도
  ↓
점진적으로 어려운 난이도 도전
  ↓
특정 콤보 또는 점수 목표 달성
  ↓
세션 종료
```

### 4.3 장기 목표

```
Easy 모드 마스터 (Perfect 판정 90% 이상)
  ↓
Normal 모드 마스터
  ↓
Hard 모드 도전 (계속 업그레이드)
  ↓
개인 최고 점수 갱신 경쟁
  ↓
온라인 리더보드 상위 진입 (추후)
```

## 5. 난이도 설계

### 5.1 게임 난이도 단계

| 난이도 | 노트 밀도 | BPM | 콤보 난이도 | 대상 플레이어 |
|--------|---------|-----|-----------|----------|
| **Easy** | 매우 낮음 | 100 | 쉬움 | 입문자, 어린이 |
| **Normal** | 중간 | 120 | 중간 | 경험 있는 플레이어 |
| **Hard** | 높음 | 140 | 어려움 | 숙련자, 마니아 |

### 5.2 난이도 특성

#### Easy (BPM 100)
- 노트 밀도: 낮음 (1/2 비트마다)
- 패턴: 단순 (한 레인 반복 또는 2개 레인 교대)
- 입력 윈도우: 넓음 (±200ms)
- 추천 대상: 게임 처음 접하는 플레이어

#### Normal (BPM 120)
- 노트 밀도: 중간 (1 비트마다)
- 패턴: 혼합 (3개 레인 무작위)
- 입력 윈도우: 표준 (±300ms)
- 추천 대상: 리듬 게임 경험 있는 플레이어

#### Hard (BPM 140)
- 노트 밀도: 높음 (2 비트마다, 트릴)
- 패턴: 복잡 (빠른 속도, 혼란스러운 배치)
- 입력 윈도우: 좁음 (±300ms는 같지만 난이도 높음)
- 추천 대상: 숙련자, 리듬 게임 마니아

### 5.3 난이도 조절 메커니즘

- **모드 자유 선택**: 언제든 원하는 난이도 선택 가능
- **점진적 해금**: 추천 순서대로 소개하되 모두 언락 가능
- **목표 기반**: "이 난이도에서 x점 이상 달성하기" 등의 목표 제시
- **경기능**: 실력 향상에 따라 자동으로 더 높은 난이도 권장

## 6. 수익화 방안

### 6.1 무료 게임 모델

Rhythm Pulse는 **무료 게임**으로 설계되되, 다음과 같은 수익화 옵션 제공:

#### A. 광고 기반 (선택적)
- **배너 광고**: 메인 메뉴 하단 (지속적)
- **보상 광고**: 게임 오버 후 광고 시청 → "재시도" 기회 (1회/게임)
- **점수 부스트 광고**: 광고 시청 → 다음 게임의 초기 콤보 +5

#### B. 구독 모델 (프리미엄)
- **Rhythm Pulse+**: 월 2,900원
  - 광고 완전 제거
  - 점수 획득량 1.2배 증가
  - 일일 특별 챌린지 추가
  - 맞춤형 음악 팩 (추후 확장)
  - 통계 및 성과 분석

#### C. DLC (음악 팩)
- **추가 음악 팩**: 4,900원
  - 새로운 음악 5곡 추가
  - 새로운 비주얼 테마 (우주, 수중 등)
  - 커스텀 리더보드

#### D. 배경음악 변경 (선택적 과금)
- **테마 음악**: 1,200원
  - 배경 음악을 특정 아티스트 곡으로 변경
  - 시각적 테마 변경 (그에 맞는 색상 팔레트)

### 6.2 수익화 철학

- **핵심 게임 무료**: 모든 난이도를 광고/과금 없이 즐길 수 있음
- **선택적 편의성**: 광고 제거와 점수 부스트만 판매
- **공정한 경쟁**: 과금 플레이어가 조작적 우위를 갖지 않음
- **거슬리지 않는 광고**: 보상형 광고 (시청 후 이익)만 제공

## 7. 차별점 및 경쟁 분석

### 7.1 경쟁사 분석

| 경쟁사 게임 | 장점 | 약점 | 우리의 차별화 |
|-------------|------|------|----------|
| **Osu\!** | 인기 높음, 커뮤니티 | 난이도 높음, 학습곡선 가파름 | 진입장벽 낮음, 더 쉬운 시작 |
| **Beat Saber** | VR 혁신, 몸 전체 사용 | 하드웨어 필요 | 브라우저 기반, 접근성 높음 |
| **Groove Coaster** | 화려한 비주얼 | 가격 높음, 모바일 최적화 부족 | 무료, 웹 기반 |
| **Crypt of the NecroDancer** | 독창적 게임 기전 | 음악 곡 수 제한 | 절차적 음악으로 무한 변형 |

### 7.2 우리의 차별점

#### 1. **절차적 음악 생성**
- 매번 새로운 음악 비트 생성
- 반복성 없음 (무한 재재 가능)
- Web Audio API로 순수 생성 (곡 파일 불필요)

#### 2. **낮은 진입장벽**
- Easy 모드부터 10분 안에 게임 이해
- 직관적 3레인 구조 (오른쪽 2개 레인 게임보다 간단)
- 복잡한 판정 규칙 없음 (Perfect/Great/Good/Miss만)

#### 3. **화려한 네온 비주얼**
- 아케이드 게임의 향수와 현대 미학의 결합
- 파티클 폭발과 화면 진동으로 만족감 극대화
- 피버 모드의 카타르시스적 경험

#### 4. **중독성 있는 콤보 시스템**
- 미스 한 번이 모든 것을 잃는 긴장감
- 콤보 숫자 증가에 따른 색상 변화로 시각적 흥분
- 피버 모드로의 점진적 상향 곡선

#### 5. **브라우저 기반 접근성**
- 별도 설치 불필요
- 모든 기기에서 플레이 가능
- 웹 표준 기술 사용

### 7.3 시장 포지셔닝

**타겟 마켓**: 
- 메인: 18-35세 리듬 게임 팬
- 서브: 아케이드 게임 향수가 있는 40세 이상

**포지셔닝 메시지**:
"네온 빛이 가득한 아케이드 세계에서 음악의 박자를 느껴보세요. 브라우저에서 즐기는 중독성 있는 리듬 게임, Rhythm Pulse\!"

**유통 전략**:
1. 웹 배포: games.eastsea.xyz/rhythm-pulse
2. itch.io 동시 배포
3. 모바일 앱화 (iOS/Android, 추후)

## 8. 향후 확장 계획

### 8.1 콘텐츠 확장
- **난이도 추가**: Extreme (BPM 160+)
- **시즈널 이벤트**: 분기별 특별 음악 팩
- **도전 모드**: 특수 조건 (예: 미스 불가)

### 8.2 게임 모드 확장
- **일일 챌린지**: 매일 다른 음악과 난이도
- **서바이벌 모드**: 계속 어려워지는 노트
- **합주 모드**: 멀티 트랙 절차적 음악
- **프리 플레이**: 모든 음악 언락

### 8.3 커스터마이징
- **음악 커스터마이징**: BPM, 악기, 박자 조정
- **비주얼 테마**: 컬러, 파티클 효과 사용자 정의
- **사운드 팩**: 다양한 비트 음향 세트

### 8.4 소셜 기능 (추후)
- **온라인 리더보드**: 전 세계 플레이어 경쟁
- **친구 대전**: 같은 곡으로 점수 경쟁
- **점수 공유**: 특정 성과 소셜 공유

## 9. 접근성

### 9.1 음성 장애인 지원
- 음악 리듬이 주 메커니즘이므로 자동으로 포함

### 9.2 시각 장애인 지원
- 음성 피드백 (타이밍 음향 신호)
- 햅틱 피드백 (진동 - 모바일에서)
- 스크린 리더 호환성

### 9.3 운동 장애 지원
- 키보드 입력 지원 (마우스 불필요)
- 커스터마이징 가능한 입력 지연

## 11. 성공 지표

### 11.1 게임 성공 측정

- **일일 활성 사용자 (DAU)**: 2,000명 이상
- **월간 활성 사용자 (MAU)**: 10,000명 이상
- **평균 세션 길이**: 8분 이상
- **일일 재방문율**: 35% 이상
- **평균 재도전 횟수**: 게임당 3회 이상
- **구독 전환율**: 5% 이상

### 11.2 사용자 만족도
- **평점**: 4.3/5.0 이상
- **긍정 리뷰**: 80% 이상
- **리플레이 의도**: 60% 이상
