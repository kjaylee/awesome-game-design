# ⚖️ Game Balancing 심화

> "모든 선택이 의미 있고, 어떤 전략도 지배적이지 않은" 상태. 밸런싱은 수학이 아니라 경험 설계다.

---

## 🔧 Machinations 프레임워크

Joris Dormans가 2012년 박사 논문에서 제안한 게임 경제 시스템 시각화 방법론. 실제 엔진 구현 전에 시스템을 다이어그램으로 설계하고 시뮬레이션.

**공식 도구**: [machinations.io](https://machinations.io/) (웹 기반, 무료/유료 티어)

### 6가지 핵심 노드

```
○ 풀 (Pool): 자원 저장소
  - 게임 내 자원(골드, HP, 탄약)을 저장하는 컨테이너
  
□ 소스 (Source): 자원 생성
  - 아무것도 없는 곳에서 자원을 만들어냄
  - 예: 골드 광산, 자연 회복, 경험치 획득
  
△ 드레인 (Drain): 자원 소멸
  - 자원이 시스템에서 완전히 사라짐
  - 예: 수리비, 사망, 소비 아이템 사용
  
◇ 컨버터 (Converter): 자원 변환
  - 한 자원을 다른 자원으로 변환
  - 예: 재료 → 아이템 (크래프팅), XP → 레벨
  
● 트레이더 (Trader): 양방향 교환
  - 두 자원을 동시에 교환
  - 예: 상점 (골드 ↔ 아이템)
  
→ 자원 연결 (Resource Connection): 자원 흐름
  - 시간당 X단위 이동
```

### 피드백 루프 설계

**포지티브 피드백 (강화 루프)**:
```
결과 → 더 강한 원인 → 더 큰 결과 (폭주하는 나선)

예시:
[골드 생성] → [업그레이드 구매] → [더 빠른 골드 생성]
     ↑_______________________________________________↓

게임 적용:
+ 초반 선두 플레이어가 계속 유리해지는 스노우볼 효과
+ 아이들 게임의 초반 가속
- 대전 게임에서 일방적 우위로 재미 감소

대응 메카닉:
- 수확 체감 (Diminishing Returns): 레벨이 오를수록 효율 감소
- 적 스케일링: 플레이어가 강해질수록 적도 강해짐
- 캐치업 메카닉: 뒤처진 플레이어에게 보너스
```

**네거티브 피드백 (균형 루프)**:
```
결과 → 약화된 원인 → 줄어드는 결과 (평형 유지)

예시:
[높은 점수] → [더 강한 적 스폰] → [점수 유지 어려움]
      ↑_______________________________________________↓

게임 적용:
+ 실력 격차가 있어도 경쟁이 유지되는 효과
+ 시스템의 자기 조정 능력
- 과도하면 플레이어의 진보감 차단

대응 메카닉:
- 허용 구역 (Slack): 일정 수준까지는 네거티브 피드백 없음
- 전문화 보상: 최적화된 빌드에 대한 우위
```

### 경제 시스템 루프 설계 예시

**RPG 경제 시스템**:
```
[몬스터 처치]
    ↓
[XP 획득] → [레벨업] → [스탯 증가]
    ↓                      ↓
[골드 획득]          [더 강한 적 처치 가능]
    ↓
[장비 구매] → [전투력 증가]
    ↑
[드레인: 수리비/소모품/죽음 패널티]

인플레이션 방지 메카닉:
- 수리비 (골드 드레인)
- 고레벨 지역 진입 비용
- 소모품 소비 강요
- 경매장 세금 (PvP 서버)
```

**전략 게임 경제**:
```
[수집 유닛] → [자원 풀] → [생산 건물] → [군사 유닛]
    ↑              ↑                              ↓
[지도 탐색]   [건물 투자]              [전투 → 영토 획득]
                                              ↓
                                    [더 많은 수집 공간]
```

## 📊 수치 밸런싱 공식

### 스탯 스케일링 곡선

**선형 성장** — 예측 가능, 단조롭:
```
stat(n) = BASE + n × INCREMENT
예: HP = 100 + 레벨 × 50
레벨 1: 150 / 레벨 10: 600 / 레벨 50: 2,600
적합: 체스, 보드게임 스타일
```

**기하급수 성장** — 후반 폭발:
```
stat(n) = BASE × MULTIPLIER^n
예: HP = 100 × 1.08^레벨
레벨 1: 108 / 레벨 10: 215 / 레벨 50: 4,690 / 레벨 99: 195,360
적합: 대부분의 JRPG, 아이들 게임
```

**로그 성장** — 초반 빠름, 후반 느림:
```
stat(n) = BASE × log(n + 1) × SCALE
예: DMG = 10 × log(레벨 + 1) × 15
레벨 1: 9 / 레벨 10: 15 / 레벨 50: 25 / 레벨 99: 30
적합: FPS 총기 데미지, 스킬 쿨다운 감소
```

**S-커브 성장** — 중반 최대 성장:
```
stat(n) = MAX / (1 + e^(-k(n - MID)))
중반 레벨에서 가장 빠르게 성장
적합: 모바일 게임 진행 시스템
```

### 전투 밸런싱

**DPS vs TTK 계산**:
```
DPS (초당 데미지) = 공격력 / 공격 속도
TTK (적 처치 시간) = 적 HP / DPS

목표 TTK 기준:
- 일반 잡몹: 2~5초 (DPS의 2~5배 HP)
- 엘리트: 10~20초
- 중간 보스: 60초
- 최종 보스: 180~300초

플레이어 생존 시간 계산:
Player TTK = 플레이어 HP / (적 DPS × 동시 공격 적 수)
안전 마진: Player TTK ≥ 적 TTK × 1.5 (일반 난이도)
```

**록-페이퍼-시저 밸런싱** (삼각 균형):
```
A가 B를 이기고, B가 C를 이기고, C가 A를 이김
예: 고지대 → 평지 → 저지대 → 고지대 (지형 유리)
    돌격 → 방어 → 사격 → 돌격 (보병 역할)

중요: 각 요소의 "이기는 비율"이 유사해야 함
예: A vs B = 60:40, B vs C = 55:45, C vs A = 65:35 (허용)
    A vs B = 90:10 (지배적, 균형 파괴)
```

### 경제 밸런싱

**골드 수입/지출 시뮬레이션**:
```
시간당 순수입 = 시간당 수입 - 시간당 지출
목표: 플레이어가 항상 "약간 부족함"을 느껴야 함
      (너무 부족하면 좌절, 너무 여유로우면 목표 없음)

황금 비율: 지출 최적화 = 수입의 70~90%
           저축 여유 = 10~30%
```

## 🏆 PvP 밸런싱 이론

### ELO 시스템 심화

체스에서 유래한 스킬 레이팅 시스템. 모든 기반 PvP 매칭 시스템의 근원.

**공식**:
```
예상 승률 = 1 / (1 + 10^((상대 ELO - 내 ELO) / 400))

ELO 변화량 = K × (실제 결과 - 예상 승률)
실제 결과: 승리=1, 무승부=0.5, 패배=0

예시: 내 ELO=1200, 상대=1400, K=20
예상 승률 = 1 / (1 + 10^(200/400)) = 0.24 (24%)
승리 시: +20 × (1 - 0.24) = +15.2 ELO
패배 시: +20 × (0 - 0.24) = -4.8 ELO
```

**K값 최적화**:
```
신규 플레이어 (< 30게임): K=40
  → 빠른 초기 배치, 기존 플레이어 영향 최소화
일반 플레이어: K=20
  → 안정적 변동
상위 플레이어 (2400+): K=10
  → 높은 ELO에서의 안정성
```

**ELO의 한계**:
- 1:1 게임에만 정확 (팀전에는 조정 필요)
- "요새" 현상: 높은 ELO 플레이어가 게임 안 하면 인플레이션
- 멀티 포지션 게임에서 포지션별 스킬 미반영

### MMR (Matchmaking Rating) 설계

ELO를 기반으로 현대 게임에서 확장된 시스템.

**League of Legends 스타일 MMR**:
```
MMR = ELO 기반 내부 숫자 (플레이어에게 숨겨짐)
티어 (Bronze/Silver/Gold) = MMR 구간의 표시
LP (리그 포인트) = 티어 내 진행도

분리 이유:
- MMR: 실제 매칭 품질 (정확성 우선)
- 티어/LP: 동기부여 시스템 (성취감 우선)
```

**매칭 속도 vs 품질 트레이드오프**:
```
대기 허용 시간별 매칭 범위 확대:
0~30초: ±50 MMR 범위
30~60초: ±100 MMR 범위
1~2분: ±200 MMR 범위
2분+: 최선의 매칭 (아무나)

권장: 대기 1분 이내 매칭이 80% 이상
     (1분 이상 기다리면 경험 품질 저하)
```

**티어 분포 설계**:
```
이상적인 정규분포:
Bronze: 20%
Silver: 35%
Gold: 30%
Platinum: 10%
Diamond: 4%
Master+: 1%

주의: 실제 게임은 인플레이션으로 상위 티어 비율이 늘어나는 경향
해결: 시즌 초기화, 승급/강등 히스테리시스
```

### 챔피언/캐릭터 밸런싱

**역할(Role) 균형**:
```
각 역할의 플레이 비율이 있을 때:
지원(Support) 픽률 < 10% → 버프 또는 메타 의존성 증가
딜러(DPS) 픽률 > 60% → 탱커/서포트 강화 필요

이상적: 모든 역할의 승률이 50% ±3% 범위
특정 챔피언 승률 > 55% → 즉시 너프 검토
```

**밸런싱 패치 원칙**:
1. **작게 조정**: 10% 이상 변경은 과도할 가능성이 높음
2. **하나씩 변경**: 동시에 여러 요소 변경 시 원인 파악 불가
3. **데이터 기반**: 직감이 아닌 통계 기반 결정
4. **소통**: 변경 이유를 플레이어에게 설명 (패치 노트)

## 📱 아이들/캐주얼 게임 수치 설계

### 진행 곡선 설계

**업그레이드 비용 공식**:
```
cost(n) = BASE_COST × MULTIPLIER ^ n

일반적인 MULTIPLIER 범위:
캐주얼: 1.07~1.10 (완만한 성장)
미드코어: 1.12~1.15 (중간)
하드코어: 1.18~1.25 (가파른 성장)

예시 (BASE=10, MULTI=1.15):
업그레이드 1: 10 / 5: 20 / 10: 40 / 20: 164 / 50: 1,083
```

**진행 시간 설계**:
```
각 마일스톤 간 예상 플레이 시간:
처음 보상 획득: 5분 이내 (훅 타이밍)
첫 업그레이드: 15분 이내
첫 프레스티지/리셋: 4~8시간 누적
두 번째 프레스티지: 2~3시간 (가속감)
콘텐츠 엔드: 30~100시간

무과금 플레이어: 위 시간의 3~5배
```

**오프라인 진행**:
```
오프라인 수익 = 온라인 시간당 수익 × 오프라인 시간 × 효율 계수

효율 계수 권장값:
일반 아이들 게임: 50% (온라인 유도)
야간 수익 강조 게임: 80~100%
하드코어 아이들: 25% (적극적 플레이 필수)

최대 누적 시간: 8~24시간 권장
(너무 길면 "어차피 안 봐도 된다" 심리)
```

### 세션 길이 설계

```
목표 세션 길이별 설계:
스낵게임 (3~5분): 즉각 피드백, 짧은 루프
미드코어 (15~30분): 진행감, 작은 마일스톤
코어게임 (60분+): 깊은 시스템, 캠페인

Push 알림 타이밍:
건설/제작 완료: 즉시
에너지 회복: 50% / 100% 시점
이벤트 종료: 1시간 전, 10분 전
```

## 🎰 가챠/랜덤 보상 설계

### 천장(Pity) 시스템 설계

```
기본 천장 (Hard Pity):
획득 확률: 0.6% (일반 전형적)
천장: 90연차 이내 최고 등급 확정

소프트 천장 (Soft Pity):
76연차부터 확률 급등:
76: 6% / 80: 32% / 85: 57% / 90: 100%

실제 기대값 계산:
E[연차수] = Σ(n × P(n연차에 처음 획득))
하드 천장만 있을 때: 약 62연차
소프트 천장 있을 때: 약 45~55연차
```

### 확률 유형별 특성

```
베르누이 (독립 시행):
매 연차 동일 확률, 천장 없음
문제: 극히 낮은 확률의 연속 실패 가능성
예: P(100연차 미획득) = (1-0.006)^100 = 0.55 = 55%!

천장 없는 구조는 윤리적으로 문제가 있음.
```

### 드롭 테이블 설계

```
가중치 기반 랜덤:
[일반 아이템]: 600 (60%)
[희귀 아이템]: 300 (30%)
[에픽 아이템]: 80 (8%)
[전설 아이템]: 19 (1.9%)
[신화 아이템]: 1 (0.1%)

합계: 1000 = 100%

중복 처리:
중복 아이템 → 분해 재료
분해 재료 × N개 → 원하는 아이템 교환
(직접 구매 루트 제공으로 강박 감소)
```

### 윤리적 가챠 체크리스트

- [ ] 모든 확률 인게임 공시
- [ ] 천장(pity) 시스템 존재
- [ ] 중복 구제 수단 (교환/분해)
- [ ] 무과금으로도 최고 등급 획득 가능 (시간 투자)
- [ ] 월별 지출 한도 설정 옵션
- [ ] 미성년자 보호 장치 (연령 인증, 보호자 설정)
- [ ] PvP에서 가챠 보상이 직접적 이점 없음
- [ ] 가챠 결과가 게임 클리어에 필수가 아님

## 🧪 밸런싱 프로세스

### 밸런싱 단계 (5단계)

```
1단계: 이론 밸런스 (Theory Balance)
   도구: 스프레드시트, Machinations
   목표: 극단적 수치 제거, 일관된 스케일링
   산출물: 스탯 테이블, 경제 시뮬레이션

2단계: 봇 시뮬레이션 (Bot Simulation)
   도구: 자동화 스크립트, 몬테카를로 시뮬레이션
   목표: 수천 게임의 통계적 결과 분석
   산출물: 승률 히트맵, 빌드 효율 순위

3단계: 내부 플레이테스트 (Internal Playtest)
   목표: 직관적 체감 검증 ("숫자가 맞아도 재미없을 수 있다")
   방법: 팀 내 격주 플레이테스트

4단계: 외부 플레이테스트 (External Playtest)
   목표: 타겟 유저 체감 난이도, "익숙하지 않은 눈"
   방법: 포커스 그룹, 베타 테스트

5단계: 라이브 데이터 분석 (Live Data)
   도구: Firebase Analytics, Amplitude, Mixpanel
   목표: 실제 플레이어 행동 데이터 기반 조정
   지표: 드롭 포인트, 빌드 다양성, 수익화 전환률
```

### 밸런싱 핵심 지표

```
게임플레이 지표:
- 챔피언/캐릭터별 픽률 (이상: ±30% 범위)
- 챔피언/캐릭터별 승률 (이상: 50% ±5%)
- 평균 게임 길이 (기준에서 ±20% 이내)
- 퍼스트-피크/세컨드-피크 드롭률 (튜토리얼 통과 후 이탈)

경제 지표:
- 플레이어별 평균 골드 보유량
- 아이템 사용 비율 (특정 아이템 사용률 > 80% = 지배적)
- 스킵 구매 비율 (대기 시간 건너뛰기)
```
